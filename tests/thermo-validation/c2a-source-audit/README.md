# C2-A 第三轮：VLE 原文核对与气相密度来源审计

日期：2026-10-22。上一轮结果已获所有者认可，提交为 `0bc33f59`，未 push。本轮仍只推进 C2-A，结果供审定；C2-B / C3 未实施。

## 结论与证据级别

三个关键冲突点在原论文的公开预览文本中均能找到，数值、组分编号、摩尔分数口径和单位换算与已冻结的 ThermoML 记录一致，**目前没有支持修正这三条记录的转录错误证据**。这不是全表认证：ACS 正式全文未取得，公开预览的原表图像核验也未完成（浏览器读取超时）；无法可靠定位的空白格保持未判定，不据此新增或重排记录。

原文声明的不确定度与 ThermoML 编目人员评定的扩展不确定度有明显差异。本轮将两者分开保存，未替换原记录或放宽门槛。54 次泡点扰动计算全部返回；三点在两个后端下的汽相组成仍不满足原 0.02 判据。采样区间也未与原文声明的组成不确定度区间重叠，但这不是连续区间证明或统计显著性检验。

**未新增合格的丙烷 / 正丁烷混合物气相密度实测点。** 新线索定位到 GPA RR-147，公开目录提供会员访问 / 购买入口而没有逐点数据。本轮没有账户登录、购买或代发索取邮件。来源尚未取得，不能宣称已补齐气相密度及其不确定度。

## 混合物气相密度：来源与缺口

| 来源 | 本轮取得的证据 | 可否计入 |
| --- | --- | --- |
| [GPA RR-147 官方目录](https://www.gpamidstream.org/publications/technical-research-reports/) | Holcomb / Magee / Haynes 的密度报告，Project 916，1995；全文需相应访问权限，未取得逐点表或不确定度 | 否；其标题不能证明候选域中有二元气相数据 |
| [NIST 1995 年度技术报告](https://nvlpubs.nist.gov/nistpubs/Legacy/IR/nistir5828.pdf) | PDF 第 143 页 / 印刷 p.133 页图已核验：报告二元单相 PρT（200–400 K、至 35 MPa）及共存密度 / VLE（240–420 K），但没有本轮可评分逐点表 | 否；这些是研究范围，不能证明每个二元气相点落入候选域；文中的 0.5% 是贸易计量相关性质层面的项目成果，不能代作逐点气相密度不确定度 |
| [Nysewander 1940 DOI](https://doi.org/10.1021/ie50361a026) / [1938 学位论文](https://thesis.caltech.edu/16876/1/Nysewander_CW_1938.pdf) | 前轮的访问限制与只有曲线的证据保持；本轮未获得新原表 | 否；不从不明确曲线补造逐点数据或不确定度 |
| [Miyamoto 2008](https://doi.org/10.1016/j.jct.2007.06.014) | 原包已有的二元 PρTx 来源明确属于压缩液体 | 否；不能因题名含 PρTx 就充作气相证据 |

正式纳入至少需要：成分标识及摩尔组成、T、P、气相密度、相态依据、单位、逐点来源，以及 T/P/组成/密度的不确定度或可追溯评定方法、覆盖因子 / 置信信息。缺项应记录为缺项；模型预测、纯组分密度和多组分天然气数据不能替代这组二元实验。
