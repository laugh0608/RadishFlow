以下是按依赖推进的能力阶段，不是一次性实施清单或发布日期承诺。2026-10-23 所有者再次确认基础架构优先：近期以 P1 / P2 的工程、装配、运行、命令和结果链路为主线，具体按下方 AF 切片推进。P2 已有变量读写、受控动作及 B3-4 / B3-5 无界面消费者；沿用这些基础，按真实断点补齐。其他平台原生验收按 2026-09-15 确认的阶段节点集中验证，P1 未测项不视为完成。已知数据安全和内存安全问题随时处理。

| P1 基础功能闭环 | 普通用户可完成建模与修改，无需依赖固定演示流程 | 组分 / 物性选择、对象与连接编辑、参数、单位输入 / 显示、undo / redo、规格检查 / 诊断、结果、保存 / 重开；逐项补缺口 | 选定编辑任务从空白项目可完成；命令、revision、错误和结果一致；成功与失败路径有代码及真实窗口证据 |
| P2 运行与扩展基础 | 提供可观察运行和变量树式自动化入口 | 输入快照、任务 / 取消、变量 / 单位 / 动作元数据、浏览查询、命令写入、确定性工作流、COM / 无界面适配、录制回放 | GUI / API 操作语义一致；从创建对象到参数、诊断、运行与结果可自动化；录制脚本可参数化回放；取消不误提交旧结果 |

| P4 多求解策略 | 按问题特征使用序贯模块、联立模块、联立方程及混合分区 | 模型能力、变量 / 方程与耦合残差、导数、缩放、结构检查、初始化与可替换后端 | 同一物理问题在支持的策略间结果一致；不支持组合显式拒绝；诊断能回到领域对象 |

| P6 分布参数瞬态 | 逐步支持管道、井筒与网络的空间和时间变化 | 空间离散、输运与闭合关系、边界条件、热耦合、多相及协同仿真 | 先单相后复杂模型；空间 / 时间收敛、守恒、波传播与选定实验基准通过，耦合误差可评估 |
| P7 工程研究与生态扩展 | 将可信模型用于更完整的工程任务 | 参数估计、敏感性 / 优化、反应与行业包、APC / MPC 离线研究、数据协调、报告、能效 / 排放 / 经济分析及外部集成 | 每个扩展有明确消费者、独立验收和版本兼容要求，不以基础求解收敛代替专业结论 |

依赖按切片判断：P5 需要具备所用模型的物性、动态方程和时间积分能力，但不必等待 P3 的所有设备或 P4 的全部求解策略完成；P7 的基础报告和 API 可在 P1 / P2 随需求交付。高级算法和动态探索不能成为 P1 编辑 / 保存闭环的前置门禁，也不将数值正确性全部拖到 P3 后才检查。

递归分块与文献中的 Simultaneous Modular 分别处理：前者在 P3 演进执行计划，后者在 P4 按需要联立模块间耦合变量。模型树、变量浏览树与求解树不要求同构；不能把画布分组或重复运行循环块当作已经实现收敛算法。

P2 的自动化按可交付切片展开：先做变量 / 动作描述和只读浏览，再接入统一命令写入、创建 / 连接 / 运行与首个外部适配器（Windows COM 为明确目标），随后实现录制、参数化脚本和重复工况回放。运行任务与取消能力按其依赖同步完善；不以整个 P2 一次性交付为前提。

### 与数值研究和 C2 的关系

- C2-A 的 PR 相平衡 / 液体密度对比方案已获认可，属于专项离线验证，实施顺序服从基础主线。液体密度候选、参数依据与原失败记录归 [热力学专题](thermo/mvp-model.md#c2-a-后续方法对比与排期)，不作为 AF1—AF6 的统一前置。
- **C2-B / C3 暂不实施。** AF2 只整理现有模型装配；AF3 / AF5 的任务身份与来源契约不包含新 PR 内核、相密度 / 流量产品链或流程到设备的物理关联。共享基础不能用于变相开工这些切片。
- 物性、单元、数值策略和时间相关模型在基础接口内逐步充实；每个能力保留独立适用域、守恒、精度和鲁棒性门禁。方法欠缺不阻塞无关编辑 / 存储功能，也不允许用假数据让工程计算看似通过。
- 不提前搭完整插件平台、远端调度、通用 SDK 或所有模式统一大接口；也不要求先搬空 Studio / 填满 `rf-canvas`。具体抽象以当前消费者和可验证收益决定。

QS2 与 QS3 不强制串行；首个 EO 块不等待全部设备支持 EO，也不要求所有问题先取得完整 SM 收敛解。MC1 / MC2 提供所需模型工厂和物性上下文，第三方加载只在实际案例需要时依赖 MC3；完整插件系统、动态和 SDK 不作为前置。DS 反算可先基于局部或 SM 路径实施。

验收比较同一物理模型、版本、规格及解分支下的结果、残差和衡算，同时记录初始化、局部 / 物性调用、总耗时与成功率。迭代更少不自动证明更快；多根不要求不同初值找到同一解。详细矩阵由专题维护，工程精度仍由物性和单元独立证据支持。
