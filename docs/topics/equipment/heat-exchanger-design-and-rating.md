# 换热器设计与性能校核

更新时间：2026-09-16

## 用途与状态

用途：规划双侧换热器的热工计算、初步面积估算、几何设计和热力 / 水力校核。
读者：维护换热设备、焓模型、输运物性、规格、UI 和工程验证的协作者。
不包含：完整 EDR 同等能力承诺、所有结构与相变模型、机械强度或制造认证。

- 层级：二级功能；父专题：[设备设计与性能校核](../equipment-design-and-rating.md)。
- 关联：[Heater / Cooler](../unitops/heater-cooler.md)、[现有物性限制](../../thermo/mvp-model.md)、[单位](../units-and-quantity-system.md)、[规格分析](../modeling-assistance-and-specifications.md)。
- 状态：Draft / 规划已确认 / 未实现。现有 Heater / Cooler 只有指定出口温压功能，不能代表双流体换热器。

## 目标与首版范围

用户可以给定冷热侧工况和目标估算换热需求与面积，也可以给定设备几何校核出口、热负荷和压降。独立任务和流程集成共用计算能力，长期参考 [Aspen EDR](https://www.aspentech.com/en/products/engineering/aspen-exchanger-design-and-rating) 的设备工程工作流。

首版从有限工况的单相双侧换热出发，明确绝热外边界 / 热损失假设、流动配置和规格组合。给定 U 的面积估算是初步计算，详细设计需另补几何相关传热与水力模型；相变、污垢演变、热虹吸、空冷、板翅、振动等分期评估。

## 任务、物性与规格

| 任务 | 主要已知量 | 结果及边界 |
| --- | --- | --- |
| 双侧热工计算 | 两侧入口、流量、物性及足够且独立的热工规格 | 出口、热负荷和收支；不能过指定两侧出口与热负荷 |
| 初步面积估算 | 可行工况、给定或有依据的 U、流动配置及修正关系 | 所需面积、温差 / 逼近条件和假设；不伪装为已完成几何设计 |
| 性能校核 | 已知结构 / 尺寸、冷热侧工况、相应关联式 | 传热能力、出口、两侧压降及限制条件 |
| 设计搜索 | 目标热负荷 / 出口、允许压降、结构选择、污垢及其他约束 | 可行候选几何及权衡；不可行时报告具体冲突 |

先建立可靠的双侧焓平衡；涉及相变时需要一致参考态和潜热，涉及详细传热 / 压降时需要对应的密度、黏度、导热系数等数据及适用范围。不能用现有常热容演示焓直接证明真实设备热负荷准确。

面积估算可评估 LMTD 或其他适合选定配置的方法；温差符号、相等温差极限、修正系数、夹点和所选流型的可行性必须明确。不得把不同流型下的出口温度交叉一概判错，也不能无条件对温差取绝对值来掩盖不可行规格。具体关联式、结构类型、求解方法与精度在 H0 决定。

## 工作流与状态

选择设计 / 校核任务→输入或引用冷热侧工况→选择模型及规格→填写所需 U 或几何与准则→检查→计算→查看温度 / 热负荷 / 压降与依据→比较 / 采纳→保存输出。

- 工艺需求、几何、计算方法、设计准则和结果分别管理，推荐不自动覆盖输入。
- 双侧端口、压力边界和热量符号由正式模型定义，不在 UI 拼接两只 Heater 来冒充设备模型。
- 只读引用流程工况的计算和回写流程的耦合模型分别验收；回写压降 / 出口改变流程时需正式重算和过期管理。
- 采用面积、有效容积等可供未来动态使用；壁体热容、流体积存、初值和空间离散是独立补充条件。
- 输入 / 输出共用单位元数据，温差与温度、U 与面积的复合单位不能套用绝对温标偏移。报告消费有身份的设备结果，不在模板重算热工。
- 专项输入、结构示意与校核结果在主工作区评审，快速参数仍可由检查器引用同一对象；不预先固定必须使用旧右侧三 tab。

## 工况、公用工程与方案权衡

冷热侧引用 [工程设计基础](../engineering-basis-and-cases.md) 中的公用工程等级 / 供回条件或显式覆盖，标注来源。设计目标和可调整流量由 [规格求解](../flowsheet-modeling-and-solve.md#设计规格求解规划尚未实现) 管理，不能同时固定所有出口条件再额外施加热负荷目标。

H1 / H2 先保证单工况热工；H3 / H4 逐步覆盖季节供水变化、负荷范围和清洁 / 指定污垢状态，同一几何逐工况校核，分别显示热负荷、温差、两侧压降与控制工况。首版支持指定污垢热阻不等于能够预测随时间结垢。可行候选比较面积、结构、热工 / 水力余量与适用性，不以面积更大自动排名；低负荷控制或凝结水排出等只有所需模型就绪才作判断。

公用工程结果注明所需流量、温压 / 相态与供回条件，供给数据缺失时不声称供应足够。跨工况失败必须保留。工程计算表记录同一几何、所用模型 / 关联式、参数来源、运行身份和未完成项。增加单工况达标但另一工况超压降或热工不足的验证案例，完整机械和制造结论保持独立。

## 切片与验收

| 切片 | 范围 | 退出标准 |
| --- | --- | --- |
| H0 模型与数据准备 | 选定单相工况、流型、焓 / 输运性质、规格及独立案例 | 可复核模型和数据来源，当前缺口及范围明确 |
| H1 双侧热工闭环 | 双侧物料 / 能量平衡及足够独立规格 | 热负荷和出口有独立基准；欠 / 过指定、热损失假设与不可行工况可解释 |
| H2 初步面积 | 给定 U 和所需流动修正，估算面积 | 极限温差、夹点、配置适用性和单位一致；明确标为初步计算 |
| H3 几何与校核 | 首种设备结构、几何相关传热 / 压降 | 热工与两侧水力独立对照；规格 / 几何保存重开与流程关联可靠 |
| H4 深化 | 设计搜索、多工况、相变与其他结构按需求进入 | 每项新增能力有数据、关联式适用域、数值与工程验收 |

最小验证包括能量符号与收支、极限温差、两侧不同热容 / 流量、配置差异、无可行解、单位等价、缺数据、源结果过期、采纳 / Undo / Redo 和保存重开。离散模型出现后另验空间收敛；动态模型出现后另验时间收敛，不将两者作为 H1 / H2 的统一前置条件。

下一步：先按 H0 明确有限工况的模型和焓要求，H1 随 P3 能量闭环推进；不等待所有动态与瞬态功能完成。
