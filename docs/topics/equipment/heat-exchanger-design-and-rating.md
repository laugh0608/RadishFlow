## 用途与状态

用途：规划双侧换热器的热工计算、初步面积估算、几何设计和热力 / 水力校核。

不包含：完整 EDR 同等能力承诺、所有结构与相变模型、机械强度或制造认证。

- 层级：二级功能；父专题：[设备设计与性能校核](../equipment-design-and-rating.md)。
- 关联：[Heater / Cooler](../unitops/heater-cooler.md)、[现有物性限制](../../thermo/mvp-model.md)、[单位](../units-and-quantity-system.md)、[规格分析](../modeling-assistance-and-specifications.md)。

## 目标与首版范围

用户可以给定冷热侧工况和目标估算换热需求与面积，也可以给定设备几何校核出口、热负荷和压降。独立任务和流程集成共用计算能力，长期参考 [Aspen EDR](https://www.aspentech.com/en/products/engineering/aspen-exchanger-design-and-rating) 的设备工程工作流。

首版从有限工况的单相双侧换热出发，明确绝热外边界 / 热损失假设、流动配置和规格组合。给定 U 的面积估算是初步计算，详细设计需另补几何相关传热与水力模型；相变、污垢演变、热虹吸、空冷、板翅、振动等分期评估。

## 任务、物性与规格

| 任务 | 主要已知量 | 结果及边界 |
| --- | --- | --- |
| 双侧热工计算 | 两侧入口、流量、物性及足够且独立的热工规格 | 出口、热负荷和收支；不能过指定两侧出口与热负荷 |
| 初步面积估算 | 可行工况、给定或有依据的 U、流动配置及修正关系 | 所需面积、温差 / 逼近条件和假设；不伪装为已完成几何设计 |
| 性能校核 | 已知结构 / 尺寸、冷热侧工况、相应关联式 | 传热能力、出口、两侧压降及限制条件 |
| 设计搜索 | 目标热负荷 / 出口、允许压降、结构选择、污垢及其他约束 | 可行候选几何及权衡；不可行时报告具体冲突 |

先建立可靠的双侧焓平衡；涉及相变时需要一致参考态和潜热，涉及详细传热 / 压降时需要对应的密度、黏度、导热系数等数据及适用范围。不能用现有常热容演示焓直接证明真实设备热负荷准确。

面积估算可评估 LMTD 或其他适合选定配置的方法；温差符号、相等温差极限、修正系数、夹点和所选流型的可行性必须明确。不得把不同流型下的出口温度交叉一概判错，也不能无条件对温差取绝对值来掩盖不可行规格。具体关联式、结构类型、求解方法与精度随对应切片冻结。

## 工作流与状态

选择设计 / 校核任务→输入或引用冷热侧工况→选择模型及规格→填写所需 U 或几何与准则→检查→计算→查看温度 / 热负荷 / 压降与依据→比较 / 采纳→保存输出。

- 工艺需求、几何、计算方法、设计准则和结果分别管理，推荐不自动覆盖输入。
- 双侧端口、压力边界和热量符号由正式模型定义，不在 UI 拼接两只 Heater 来冒充设备模型。
- 只读引用流程工况的计算和回写流程的耦合模型分别验收；回写压降 / 出口改变流程时需正式重算和过期管理。
- 采用面积、有效容积等可供未来动态使用；壁体热容、流体积存、初值和空间离散是独立补充条件。
- 输入 / 输出共用单位元数据，温差与温度、U 与面积的复合单位不能套用绝对温标偏移。报告消费有身份的设备结果，不在模板重算热工。
- 专项输入、结构示意与校核结果在主工作区评审，快速参数仍可由检查器引用同一对象；不预先固定必须使用旧右侧三 tab。

## 工况、公用工程与方案权衡

冷热侧引用 [工程设计基础](../engineering-basis-and-cases.md) 中的公用工程等级 / 供回条件或显式覆盖，标注来源。设计目标和可调整流量由 [规格求解](../flowsheet-modeling-and-solve.md#设计规格求解规划尚未实现) 管理，不能同时固定所有出口条件再额外施加热负荷目标。

H1 / H2 先保证单工况热工；H3 / H4 逐步覆盖季节供水变化、负荷范围和清洁 / 指定污垢状态，同一几何逐工况校核，分别显示热负荷、温差、两侧压降与控制工况。首版支持指定污垢热阻不等于能够预测随时间结垢。可行候选比较面积、结构、热工 / 水力余量与适用性，不以面积更大自动排名；低负荷控制或凝结水排出等只有所需模型就绪才作判断。

公用工程结果注明所需流量、温压 / 相态与供回条件，供给数据缺失时不声称供应足够。跨工况失败必须保留。工程计算表记录同一几何、所用模型 / 关联式、参数来源、运行身份和未完成项。增加单工况达标但另一工况超压降或热工不足的验证案例，完整机械和制造结论保持独立。

## H0 冻结方案与独立基准

2026-11-21 复用[双进料显热工程](../../../examples/flowsheets/two-feed-single-vapor-sensible.rfproj.json)的 B、A 两股分别作为热侧和冷侧，各自独立进出。工况为稳态逆流，外边界绝热，两侧不混合且压降为零。两股按同一个气相常热容模型求焓，`298.15 K` 为参考态，算例温区 `280–420 K` 含端点，固定绝对压力为 `100000 Pa`。热侧 B 为 `360 K、3 mol/s、50 J/(mol·K)`，冷侧 A 为 `300 K、2 mol/s、30 J/(mol·K)`。因此热容流率 `C_h = 150 W/K`、`C_c = 60 W/K`。算例物性是合成输入。

三种规格恰选一项：热负荷 `Q`、热侧出口温度或冷侧出口温度。正 `Q` 从热侧向冷侧传递。热侧实际焓流变化应为 `−Q`，冷侧应为 `+Q`。直接计算时 `T_h,out = T_h,in − Q/C_h`、`T_c,out = T_c,in + Q/C_c`，由任一指定出口温度反求同一个 `Q`。两侧入口流量必须正且有限，热侧入口温度不得低于冷侧。零负荷使两侧分别保持入口状态，等温进料可在零负荷下运行。

逆流端温差为 `T_h,in − T_c,out`、`T_h,out − T_c,in`。正负荷必须使两端温差均为正。`min(C_h,C_c) × (T_h,in − T_c,in)` 为夹点极限，达到极限报告夹点，超过极限报告热负荷不可行。温度交叉的判据取成对的逆流端温差。温压、流量、热容、规格和计算证据应为有限值，超域或反向传热给出明确错误。

从工程文件直接取数，用有理数逐侧计算出口、参考焓和逆流端温差。

| 指定负荷 | 热侧出口 | 冷侧出口 | 两端温差 | 热侧进／出焓流 | 冷侧进／出焓流 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 0 W | 360 K | 300 K | 60／60 K | 9277.5／9277.5 W | 111／111 W |
| 3000 W | 340 K | 350 K | 10／40 K | 9277.5／6277.5 W | 111／3111 W |
| 3600 W（夹点极限） | 336 K | 360 K | 0／36 K | 9277.5／5677.5 W | 111／3711 W |

H1 先验指定负荷，再验指定热侧 `340 K` 和冷侧 `350 K` 都反求 `3000 W`。出口温度和端温差与独立基准之差 `≤ 1e-8 K`，热负荷和焓流与基准之差 `≤ 1e-6 W`。用实际进出口物化物流复核各侧逐组分流量，绝对残差 `≤ 1e-10 mol/s`。各侧及整体能量绝对残差 `≤ 1e-6 W`，缩放残差 `≤ 1e-10`，尺度沿用 `max(1 W, Σ|Ḣin| + Σ|Ḣout| + |Q外边界|)`。整体外边界的 `Q` 为零。验收同时覆盖规格缺失或冲突、零流、温压越域、缺物性、反向和非有限值。

H1 通过 `rf_unitops::heat_exchanger::calculate_countercurrent` 接收两侧入口、出口标识和一种规格，返回物化出口、端温差、夹点极限及实际侧别和整体衡算。 [Core 入口](../../../crates/rf-unitops/src/heat_exchanger.rs) · [验收用例](../../../crates/rf-solver/src/tests/sensible_enthalpy/heat_exchanger.rs)

## H2 初步面积估算

`rf_unitops::heat_exchanger::estimate_countercurrent_area` 消费成功的 H1 结果中的 `Q`（W）和两端温差（K），以及调用方给定的常数 `U`（W/(m²·K)）。H2 沿用 H1 的稳态、绝热、单气相常热容和零压降假设，纯逆流的温差修正系数为 1。结果包含输入 `U`、LMTD（K）、`UA`（W/K）及初步所需面积（m²）。

- `U` 在所有工况均须有限且严格为正，否则报告 `invalid_overall_heat_transfer_coefficient`。
- 正负荷要求两端温差严格为正。H1 的 `pinch_limit` 和 `above_pinch` 发生在面积计算前，H2 入口也拒绝正负荷下的非正端温差。判据使用端温差的符号，正温差无额外的最小阈值。
- 设 `hi`、`lo` 为较大和较小的端温差。相等时 LMTD 取该共同温差。不同且均为正时，LMTD 为 `(hi − lo) / ln(hi/lo)`，用 `ln_1p((hi − lo)/lo)` 保留近等温差的有效位，比例超出浮点范围时用 `ln(hi) − ln(lo)`。随后计算 `UA = Q/LMTD`、`A = UA/U`。正负荷下的非有限或非正计算结果报告 `numeric_range`。
- 零负荷时两侧出口即各自入口，LMTD 取共同端温差，等温进料时为 `0 K`。`UA = 0 W/K`、`A = 0 m²`，直接返回零值，无需除以 LMTD。

用 65 位十进制从原双进料工程的温度、流量和热容复算。合成基准取 `U = 100 W/(m²·K)`。`Q = 3000 W` 时，热／冷侧出口为 `340／350 K`，端温差为 `10／40 K`，得到 `LMTD = 30/ln(4) = 21.64042561333445 K`、`UA = 100·ln(4) = 138.62943611198906 W/K`、`A = ln(4) = 1.3862943611198906 m²`。三种 H1 规格分别对照同一基准，LMTD、UA、面积的绝对误差分别须 `≤ 1e-8 K`、`≤ 1e-8 W/K`、`≤ 1e-10 m²`，三种规格的面积差须 `≤ 1e-10 m²`。

等端验证将热侧流量设为 `1.2 mol/s`，取 `Q = 1800 W`，两端均为 `30 K`，预期 `UA = 60 W/K`、`A = 0.6 m²`。近等端以热侧流量 `1.2 ± 4e-15 mol/s` 验证两种温差顺序，LMTD 与十进制基准绝对误差须 `≤ 1e-12 K`，且位于两端温差之间。零负荷验收覆盖同温与异温入口，夹点验收沿用 `3600 W` 工况。后续几何校核和应用接入见 [H3](#h3-同心套管逆流校核)。

Core 定向验收通过三种规格、等端与近等端、零负荷、夹点及其下方的可行工况，并覆盖非法 U 与数值范围错误。 [Core 入口](../../../crates/rf-unitops/src/heat_exchanger.rs) · [验收用例](../../../crates/rf-solver/src/tests/sensible_enthalpy/heat_exchanger.rs)

## H3 同心套管逆流校核

首片为水平单程同心套管，热液走内管，冷液走环隙。外管绝热，两侧不混合。`rf_unitops::heat_exchanger::concentric_tube::rate_countercurrent` 接收有效换热直段长度 `L`、内管内径 `Di`、内管外径 `Dw`、外管内径 `Do` 和管壁导热系数 `kw`，要求 `0 < Di < Dw < Do`，长度和导热系数正且有限。计算范围为清洁光滑的直段，入口长度因子用于环隙传热，水力仅含同一有效长度的沿程摩擦。污垢、接管、弯头、局部损失和机械设计另审。

- 每侧提供入口温度（K）、绝对压力（Pa）、摩尔流量（mol/s），以及显式常数摩尔质量、定压摩尔热容、密度、动力黏度和导热系数，均须正且有限。物性附非空来源及调用方确认的单液相低可压缩温压矩形域。边界含端点，每侧入口和出口均须在域内。模型用定热容显热，压降与显热独立计算，未计黏性耗散、压力焓或相平衡。
- 计算按内管 `Dh = Di`、环隙 `Dh = Do − Dw`，用对应流通面积和质量通量构造各侧 Reynolds 数。首片域为两侧 `10000 ≤ Re ≤ 40000`、`3 ≤ Pr ≤ 8`、`L/Dh ≥ 100`，且 `0.48 ≤ Dw/Do ≤ 0.60`。以上为本切片限定的范围，不是关联式的通用适用域。
- 内管采用充分发展圆管 Gnielinski，Darcy 摩擦因子为 `(1.82 log10(Re) − 1.64)^−2`。环隙采用 Gnielinski 2009 内壁受热、外壁绝热口径，以修正 Reynolds 数求 Darcy 因子，保留 `1 + (Dh/L)^(2/3)` 与 `0.75(Dw/Do)^−0.17`，定物性使壁面物性修正为 1。两侧均用 `ΔP = f (L/Dh) ρv²/2`，`Pout = Pin − ΔP`。 [圆管传热](https://link.springer.com/article/10.1007/BF02559682) · [圆管摩擦](https://www.sciencedirect.com/science/article/pii/S0065271708701539) · [环隙关联式与实验，表 1、2](https://repository.up.ac.za/server/api/core/bitstreams/cd5c9004-a1be-4416-a5de-1cf4a03de03b/content)
- 两侧对流与圆筒壁串联，`1/UA = 1/(hi π Di L) + ln(Dw/Di)/(2 π kw L) + 1/(ho π Dw L)`，`Uo = UA/(π Dw L)`。逆流 ε–NTU 给出热负荷和出口温度，等热容流率时 `ε = NTU/(1 + NTU)`。正负荷要求两端温差为正，用 H2 的对数平均温差复核 `Q = UA × LMTD`。等温入口时 `Q = 0 W`、`LMTD = 0 K`，压降及几何决定的 `UA` 仍有效。
- 可选准则为最低热负荷和冷热两侧最高压降，阈值须有限且非负。含等值分别按 `Q ≥ Qmin`、`ΔP ≤ ΔPmax` 判定。每项返回通过、未达标或未指定，超限保留完整结果。非法输入、越域和数值闭合失败返回诊断。结果提供两侧出口温压与原摩尔流量、Re、Pr、Nu、膜系数、Darcy 因子、沿程压降、显热残差，以及两侧面积、`Uo`、`UA`、`Q`、LMTD 与闭合残差。

| 40 mol/s | 874.55342311486 | 5521.7076364371 | 297.91426274251／294.98250804012 | 9799.8969619738／23679.130040479 | 全部通过 |

#### 协议与 v13 兼容

`schema_version: 14` 沿用 `--headless query`／`execute`、请求文件相对路径、严格 JSON 和标准回执。每次调用只读取一次工程，以同一份字节生成元数据、核对指纹并装配。查询只解析已保存关联，执行才装配物性和运行任务。`current` 只属于本请求使用的工程字节及运行快照，新进程重新从 `missing` 起步。

| --- | --- |

执行依次检查请求形状、可解析工程的 ID／指纹、能力与目标、修订与身份、静态资格和来源。运行成功后用实际包和快照重验入口资格，再进入 H3 计算和出口校验。请求损坏和身份／修订冲突返回退出码 `2`（如 `invalid_request`、`different_document`、`project_conflict`、`record_conflict`）。整份保护或校核前资格拒绝返回 `3`，分别使用 `read_only_project` 或 `action_rejected`。后者携带原资格诊断及工况目标，有流股诊断时提供侧别和流股引用。稳态运行、H3 计算或计算后的出口校验失败返回 `4`、`run_failed` 和 `failed`，保留底层诊断。同一次请求仅成功完成的校核结果可呈现为 `current`。 [现行 v13 协议和错误语义](../../reference/headless-cli.md#h3-同心套管校核-cli-v13)

2026-11-22 在实施前用 macOS CLI 复核 v13，合计 10 次真实进程调用。独立 v3 的 40 mol/s 工况与独立 v4 的 50 mol/s 工况均返回 `current`、退出 `0`，冷侧限值分别为 `passed` 和 `failed`。同时含关联与独立工况的文件，空查询返回安全元数据，工况查询和尝试执行任一工况均返回退出 `3`，文档 ID 和指纹冲突均先返回退出 `2`。临时文件字节及目录条目逐次一致。
