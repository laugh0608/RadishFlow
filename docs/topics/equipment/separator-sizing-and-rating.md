## 目标与首版范围

从可靠工况与显式设计准则出发，给出可解释的初步尺寸候选；用户也可输入已有几何，检查选定准则下的能力和裕量。结果标为“初步工艺尺寸 / 准则校核”，不自动代表制造设计或所有工况下的分离效率保证。

首版先选定一种结构和有限的气液体系 / 工况，候选为立式气液分离器；卧式、多工况包络、三相、泡沫、固体和复杂内件各自扩展。具体结构、准则、数据来源和误差要求由 S0 确认，本文不冻结经验系数。

## 输入、结果与工作流

| 内容 | 要求 |
| --- | --- |
| 工况 | 明确温压、各相流量与组成、相密度；按所用方法补黏度、表面张力、粒径等数据 |
| 设计准则 | 允许气速 / 分离方法、液体停留或缓冲要求、内件、液位区间、结构比例及设计裕量；给出来源与适用范围 |
| 校核输入 | 几何尺寸、有效截面、液位及可用工作容积，区分总容积、正常持液量和缓冲容积 |
| 结果 | 候选直径 / 长度或高度、各部分容积、控制条件、准则余量、不满足项、假设与计算依据 |

用户从独立设备任务或流程 Flash Drum 进入，选择尺寸估算 / 校核，填入或引用当前工况，补齐准则后计算。比较候选，再明确采纳设备参数；保存和导出保留方法与来源。流量使用质量 / 摩尔 / 体积何种基准必须显式，密度不能由单位换算器猜出。

不能只按液体停留时间计算总体积后声称完成气液分离器设计；气相负荷与液体容积等约束需按所选方法共同检查。若某相缺席、密度差不满足方法条件、工况越界或数据不完整，返回明确的不适用 / 缺项结果。经验相关式的系数随物系、内件和单位定义可能变化，必须有来源与量纲约定。

## 多工况与控制条件

按 [工程工况矩阵](../engineering-basis-and-cases.md) 为同一几何分别校核气相处理能力、液体停留 / 缓冲条件及所选方法的其他约束；气相和液体设计可能由不同工况控制，结果应分别指出。推荐直径、高度和液位区间时保留采用工况、准则、裕量及候选权衡，不将各工况独立选型的结果拼成未经统一校核的设备。

S1 先交付明确范围的单工况，S2 / S3 随案例能力扩展同几何多工况校核，覆盖失败、相缺席与不支持行。输入来源或共享条件变化后重验，位号仅作工程识别，引用使用稳定 ID。设备计算表至少输出工况、几何、各约束控制项和未完成检查；最小基准应含气相条件控制与液体条件控制的不同案例。

## 数据与接口边界

- 相流量、密度等来自明确输入或有身份的物性 / 流程结果；记录方法、版本和适用范围。
- 几何与准则是正式输入，推荐尺寸是计算结果，采纳走正式命令；独立任务与流程关联共用模型。
- 上游变更使关联计算过期，用户手改尺寸后以新几何重新校核；禁止用旧候选覆盖当前参数。

- 首版不加入完整制造图、规范证书、泄放设计和无依据的“安全”结论。UI 内容在重设计的设备任务区域中评审。

### 方法与来源核对

2026-10-11 核对下列原始发布者资料，作为方法语义依据；只保留链接及简短归纳，不复制供应商表格、图片、软件实现或系数库。

- [Sulzer：Applying the Right Mist Elimination Physics，2012，印刷页 54](https://www.sulzer.com/en/-/media/files/products/separation-technology/articles/applying_the_right_mist_elimination_physics.pdf)：使用 Souders–Brown 关系确定表观气速；K 与分离装置及工况有关，流动分布、有效面积和安装间距影响性能。本方案不从该文的产品性能说明推导本软件具备相同效率。
- [John M. Campbell / PetroSkills：Gas-Liquid Separators Sizing Parameter，2015，式 2—3](https://www.jmcampbell.com/tip-of-the-month/2015/09/gas-liquid-separators-sizing-parameter/)：以实际工况气量和允许气速确定截面，立式气相区使用完整横截面；K 为经验参数，不能据此量化出口液滴夹带。其引用的 API / GPSA 表未作为本项目内置标准或认证依据。

以下容积 / 圆筒几何由流量×时间及圆面积直接推导；最大液层高度是本方案选择的显式工程约束，不是上述资料提供的默认关联式。不内置“通用 K”、停留时间、流量裕量或轴向间距；K 须表明是针对整台立式分离器气相区的有效设计值，单独除雾器的额定 K 不能无依据当作容器整体 K。内件规格、布置与所采用 K 不匹配时返回不适用。

### 最小输入与公式

| 输入 | canonical SI / 约束 | 来源要求 |
| --- | --- | --- |
| 工况说明、物系及操作 `T_op/P_op` | K / Pa（绝压），有限且 >0 | 声明两相存在；物性与流量须同一工况，不自动执行相平衡 |
| `Q_g/Q_l` | m³/s，各有限且 >0，操作条件下各相实际体积流率 | 不接受 `Nm³/h` 冒充实际气量；零相量返回本方法不适用，负数 / 非有限是非法输入 |
| `rho_g/rho_l` | kg/m³，`rho_l > rho_g > 0` | 给出物系 / T/P / 方法或测量依据；不从演示相分率或总体密度拆出相密度 |
| `K_eff` 与气速利用系数 `f` | m/s，K >0；`0<f<=1` | K 已包含哪些工况 / 内件折减必须记录；f 为用户额外裕量，显式填写，避免重复折减 |
| 工作容积时间 `t_work` | s，>0 | 本批定义为 LLL→NLL 的可用工作容积除以液量，不将其标成已验证的分离停留时间 |
| `h_work_max` | m，>0 | 用户明确的 LLL→NLL 最大允许工作液层高度及依据；不是固定长径比 |
| 可选完整轴向分区 | m，非负且顺序一致，必要净距须 >0 | 下切线→LLL、NLL→HLL、HLL→入口中心、入口→内件底、内件厚度、内件顶→上切线；均明确来源和是否计入工作 / 缓冲容积 |

所有必需字段初始为空；用户可以显式记录假设并采用，但 UI 与计算表仍标“条件式”。气量 / 液量是本次设计工况值，本批不另加隐藏负荷系数。物系、温压与来源信息用于适用性检查，即使不直接进入下列算式也必须捕获到计算记录。

定义 `A` 为气相区完整圆筒截面，工作液体也使用同一直径；只覆盖气相段与除雾段同径、可按全截面采用有效 K 的布置；改变有效面积的内件占据或非圆筒液位段不支持。使用 SI：

```text
u_SB    = K_eff * sqrt((rho_l - rho_g) / rho_g)
u_allow = f * u_SB
A_g     = Q_g / u_allow
V_work  = Q_l * t_work
A_l     = V_work / h_work_max
A_req   = max(A_g, A_l)
D_min   = sqrt(4 * A_req / pi)
h_work  = V_work / A_req
load_g  = (Q_g / A_req) / u_allow
```

`A_g>A_l` 为气相截面控制，反之为液体工作容积 / 高度约束控制；在声明的数值比较容差内相等则为共同控制。`D_min` 是连续的最小要求，未含制造圆整；`load_g=1` 表示达到用户定义的允许气速，f 已包含所选裕量，不等于“无安全裕量”。不得从单工况结果推断最大负荷包络。

可选 `H_TT` 仅在所有轴向区段明确且适用时等于 `h_work` 与其余不重叠区段之和，标“按给定布置相加的切线间高度”；封头、裙座和安装总高度未计算。NLL→HLL 容积为独立缓冲量，不重复算入 LLL→NLL 工作容积，不自动赋予液塞处理能力。缺少高度来源时 `H_TT=None`，保留明确未完成项。

即使输入有限，中间乘积、密度比或开方结果溢出、非正 / 非有限也必须结构化失败；不得 clamp、补默认值或输出 `Inf/NaN` 候选。接近等密度只按物理关系与实际适用资料判断，不凭任意 eps 声称临界区有效。

#### 方法与字段定稿口径

- `K_eff` 必须以当前完整圆筒截面为基准。内件自身 K、丝网有效面积和容器面积分开；参考算例中的理想化面积处理必须作为条件写明，不新增面积扣除模型或由选定直径倒算 K。
- 实际气 / 液流量与相密度保留同一参考条件。标况换算、物性估算或删去原算例的一个液相均须明确处理；改编题不能声称重新验证了相平衡。验证包内的外部数据换算不扩展产品输入转换能力。
- `P_op` 为绝压 Pa；表压转入时，参考气压单列为来源值或设计条件。T/P 不直接进入尺寸式也不能丢失来源。
- `f` 为额外气速利用系数，需说明流量或 K 已包含的裕量；不自动叠加。设计题可显式选择无额外折减，仍不是产品默认值。
- `t_work` 只对应 LLL→NLL 的圆筒工作容积。LLL / HLL 在每个工况中明示为操作、报警或联锁边界，不能凭缩写自动映射；本包设计题采用操作边界。
- `h_work_max` 是独立给定的上限；标准最小间距、正常液面以下全部库存与总停留时间不能替代该字段或工作区定义。缺少完整高度不阻塞当前截面 / 工作容积方法验证，但 `H_TT` 保持未确定。

入口在既有设备动作区提供 CSV / JSON 按钮及“使用项目单位”说明。按所选格式补扩展名；选择 `.rfproj.json` 时追加 `.calculation.csv` / `.calculation.json`，避免导出覆盖工程。已有计算表显式确认覆盖；取消、过期或写入失败保留原文件、输入 / 草稿、历史和工程脏状态。沿用既有文件写入策略，不将导出当作工程保存。自动回归覆盖两格式一致性、单位 / 精度 / 来源、未知与部分高度、资格失效、草稿、覆盖 / 取消 / 失败；macOS 补原生保存及设备页代表路径，其他平台与 I5 按原节点处理。

### S2-A 输入、方法与结果

已新增 `SeparatorRatingTask` 与 `EquipmentTask` 枚举；应用及存储集合在 S2-A2 接入。方法为 `radishflow.separator.vertical-sb-working-volume-rating` / `1`，原 S1 方法及版本不变。

| 记录 | 字段与责任 |
| --- | --- |
| 校核任务 | 现有任务 ID、revision、位号、名称、方法；一个任务持有一套给定几何与工况集合。任务仍不等于流程 unit 或完整资产目录 |
| 给定几何 | 独立 revision；必需 `internalDiameter`、`workingLiquidHeight`（LLL→NLL）；可选既有六段轴向长度。数值均用 Length 的 Direct / BasisRef / Override，保留来源。缺项可保存，必需几何缺失时不得校核 |
| 结构声明 | 几何拥有方向、气流方向、完整等径圆筒声明、内件说明及来源；本批仅支持 S1 已验证的结构域，不从工况名称推导结构 |
| 校核工况 | 稳定 case ID、revision、名称 / 用途、物系；操作 T/P、气液实际体积流量 / 质量密度、有效 K、气速利用率 f、要求工作时间共九项输入；工况拥有介质、流量基准、K 适用范围与采用来源 |
| 结果捕获 | 任务 / 工况 / 几何身份和版本、方法、解析后的 SI 值、全部绑定和来源证据；不引用会漂移的可编辑对象 |

`workingLiquidHeight` 是已给定的工作液层高度，不能回填为本工况刚好需要的高度。校核不接受 S1 的最大液层高度输入，不隐式丢弃多余字段。几何来源按尺寸 / 图纸或显式假设检查，不要求伪造流体 T/P；密度、实际流量和 K 仍按其物系、操作条件和内件依据检查。九项必需输入、正流量 / 正密度、`rho_l > rho_g`、`0 < f <= 1` 及来源采用规则沿用 S1；缺相、零流量与域外结构保持明确不支持。

以下只是已接受 S1 关系在给定圆筒几何下的代数重排，不增加经验关联式或物性精度声明：

```text
A_given      = pi * D_given^2 / 4
V_available  = A_given * h_work_given
u_allow      = f * K_eff * sqrt((rho_l - rho_g) / rho_g)
Qg_limit     = A_given * u_allow
V_required   = Ql * t_required
t_available  = V_available / Ql
Ql_limit     = V_available / t_required
load_g       = Qg / Qg_limit
load_l       = V_required / V_available
margin_g     = 1 - load_g
margin_l     = 1 - load_l
```

`Qg_limit` / `Ql_limit` 仅在该工况物性、K、f 和要求时间保持不变时成立，不是最大操作包络；`t_available` 仅表示工作容积与液量之比。f 已包含用户气速裕量，不再次乘安全系数；负余量如实显示。完整切线间高度仍由给定工作高度与六段长度相加；缓冲容积只由 NLL→HLL 段计算，不凭此宣称液塞能力。

每个约束分为“准则内 / 边界待复核 / 超限”。对负荷比采用已确认的 `1e-10` 数值比较阈值：`abs(load-1) <= 1e-10` 为边界，其余按大小判定；始终输出未舍入负荷与带符号余量，边界不自动算通过。此阈值只处理浮点比较，不是工程容差或不确定度预算，已固定为本方法版本的一部分。任一超限则本工况“存在超限”，无超限但有边界则“边界待复核”，两项均在准则内才显示“所选两项准则内”，均保留条件式及未核查声明。

区分三个维度：执行资格 Missing / Current / Failed / Stale；两项约束结论；可选布置的完整性。超限结果仍是 Current，可审阅和导出；必需数据、来源、适用域或数值范围错误才产生 Failed。缺少可选轴向段保留未知总高，不阻挡两项主校核，也不能据此标整台设备合格。所有中间量检查非有限、溢出及非法零值，不 clamp 或补默认值。

### 事务、草稿与有限多工况

所有权与失效规则见 [G2 数据方案](../engineering-basis-and-cases.md#g2-有限工况数据与事务方案2026-10-20已确认)。S2-A 产品先只允许一个校核工况；结构使用有序非空工况集合以便后续扩展，当前不增加复制、批量计算或比较入口。

G2-B 开放新增 / 显式复制 / 删除 / 排序工况，采用同一套给定几何。复制生成新 case ID 和 Missing 结果，保留共享基础引用及明确的局部覆盖，不复制运行身份。每个工况可有不同的负荷、物性和有来源的准则；比较需说明共同几何和各自准则，不自动做最坏值组合。

汇总按气相 `load_g` 与液体 `load_l` 分别取当前有效行的最大值，并保留并列控制工况。所需工况集合就是该任务保存的全部工况，不提供隐藏失败行的隐式筛选；删除工况必须显式确认覆盖范围变化。存在 Failed / Missing / Stale / 不支持行时标“覆盖不完整”，可列已完成子集的控制项，但不得称全工况控制结论。仅当所有必需行当前且两项均在准则内，才能显示“所列工况的两项准则内”；不推广到连续操作区间。任一行超限与覆盖不完整可同时存在，汇总不以单一颜色隐藏任一状态。

S2-A 增加独立校核 CSV / JSON 格式 `radishflow.separator-rating-table` / `1`，保留现有 S1 输出契约；只输出当前可用校核结果，包含超限 / 边界、给定几何、负荷与余量。G2-B 再审定矩阵输出：完整列出所需工况与缺失 / 失败 / 过期原因，旧数值不冒充当前结果；与单行输出区分格式身份。发起时捕获单位与成员 / 结果身份，写入前重验全部相关状态，相关草稿阻挡输出。

### 流程关联与采纳的进入条件

S2-C 进入前先补齐并验证真实来源能力：当前快照中的操作条件、相身份 / 组成、相流量、相质量密度及物性方法 / 数据版本必须可追溯；任何从摩尔量转实际体积量的计算都必须具备足够上下文、适用范围和独立预期。不得把理想气体估算、用户密度或相分率隐式混成“流程计算所得”。

关联契约需明确源 document / unit 或 stream / snapshot / revision / case 与物性版本。流程当前没有独立多工况身份时如实记录，不虚构 source case。刷新须预览差异并显式提交，不能随切页更换输入；源缺失、重算替换或上游变化撤销关联资格。解除关联若要保留数值，必须生成带来源捕获的独立输入，不能只删除引用标记。
