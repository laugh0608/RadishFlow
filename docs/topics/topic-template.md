# 专题文档模板

更新时间：YYYY-MM-DD

本模板是写作骨架，不代表已建立可执行专题或已获实施授权。按[组织规则](../development/agent-collaboration.md#三级规划与进度组织)选择大专题或子专题，删除不适用条目；小目标可合并章节，保留范围、失败行为、状态来源与验收。

## 用途

- 用途：要解决的用户问题或能力边界。
- 读者：设计、实施、验证及维护者。
- 不包含：其他专题拥有的规则、历史流水和未进入本期的范围。

## 专题层级

- 层级：大专题（一级轨道）/ 子专题（二级功能）。
- 主要归属：子专题仅指定一个父专题；大专题链接整体规划。
- 协同专题：相关边界与依赖，避免多个主要归属。
- 对应阶段 / 既有编号：阶段与能力分别管理，不重新编号。
- 权威设计与接口 / 数据来源：链接已有正式文档。
