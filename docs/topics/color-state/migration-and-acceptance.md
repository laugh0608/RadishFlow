# 状态呈现迁移与验收

更新时间：2026-09-23

## 用途与状态

用途：定义 V0 分批迁移、独立验收场景和证据要求。
读者：Studio、领域状态、主题、设计与测试维护者。
不包含：已完成新画板或产品迁移的声明、重复领域算法、全界面同时重写计划。

父专题：[颜色与状态系统](../color-and-state-system.md)。状态：Draft / 待实现、待验证；逐项状态以 [追踪表](requirements-traceability.md) 为准。

## 迁移顺序与边界

| 批次 | 范围与依赖 | 退出证据 |
| --- | --- | --- |
| V0 局部设计 | 随 U2 / N0 / R0—R1 核对温压流量、单位事件、状态组合与当前领域来源 | 适用 VD 决策、代表画板与状态映射评审；不需要先完成全部 N 或 V 功能 |
| U2 首批字段 | 对应输入字段、草稿、单位集设置与保存提示 | 成功 / 失败 / 未完成、来源 / 只读、焦点和独立保存路径；共用领域事实，无第二套门禁 |
| U3 结果消费者 | 变量浏览、结果表及已有复制 / 输出入口 | 同一快照 / 修订的跨视图呈现，stale / missing 门禁及输出失败作用域 |
| 规格辅助与消息接入 | 随 A1 / A2、N1 的实际规则 / 问题能力 | 规格冲突、修正重检、计数 / 定位和工程检查结论有真实来源 |
| 后续图层与设备 | 随 V1—V4 与实际几何 / 时间结果 | 数据色带和诊断分离，非彩色与减少动画等按实际能力验证 |

实施前盘点消费者当前状态来源、私有颜色与可复用诊断，不以搜索到颜色常量作为语义正确的证据。映射共用程度、旧新样式并存范围及完成判据由 VD-04 审定，避免组件各加一份状态逻辑或为统一外观改写求解 / 项目格式。

迁移记录按消费者标明未接入、已接入待验、已验证及证据；同一含义在已迁移视图间保持一致，尚未迁移者明确范围，不宣称全局统一。改色不能改变命令启用条件、运行或输出资格。工程状态与保存格式由原所有者管理，不持久化一份可反推工程状态的颜色。

## 验收场景

表中均为待验证的 V0 / 后续接入预期。场景中的后续状态只有执行者实际支持后才可产品验收，当前可以在设计样例标明规划态，不能伪装可操作。

| 场景 | 要求 | 操作与独立预期 |
| --- | --- | --- |
| VA-01 | VIS-01 | 对同一字段分别提供用户指定、计算、默认、估算、继承、未知，以及可编辑 / 只读事实；标签与操作能力分别消费来源，不由字色推导权限；状态未知不冒充通过 |
| VA-02 | VIS-02 | 切换必填空值、可选空值、未编辑值、有效 / 非法 / 未完成草稿；叠加焦点、显示单位切换与呈现待保存，分别可辨；遵守 UE-01—13 的 SI、草稿与快照不变量 |
| VA-03 | VIS-03 | 评审已求解带警告、未检查、hold、真实暂停、运行失败、历史成功但结果过期；每项指出运行 / 数值 / 结果 / 检查作用域。导出失败不改求解成功；同次终止失败不画完整成功 |
| VA-04 | VIS-04 | 用户指定 + 错误 + 焦点、只读 + 过期 + 警告 + 选择、多项活动问题及历史恢复组合，在窄布局仍可找到所有语义 / 详情；旧诊断不遮当前身份，不一致事实有可定位反馈 |
| VA-05 | VIS-05 | 首批温压流量字段和变量 / 结果表使用相同语义；单位、来源、草稿、只读原因、当前 / stale / missing 与诊断可扫读；同一数据不因页面变更来源 |
| VA-06 | VIS-06 | 单元、端口、流股有连接状态 + 诊断 + 选择；局部成功不染成全流程成功。未来 V2 叠加高温红色带仍可独立定位错误，缺值不画成零值 |
| VA-07 | VIS-07 | 同一活动问题在全局、画布、模块与列表关联同一身份 / 数量；过滤 / 已读不清问题，恢复后当前投影移除旧错误；应用通知不污染设备计数 |
| VA-08 | VIS-08 | 在拟支持主题中切换同一状态集合，领域值、严重程度和门禁保持；组件消费语义 token，角色不按页面重命名，浅色默认及未交付主题范围明确 |
| VA-09 | VIS-09 | 灰度、色觉差异模拟下辨认错误 / 警告、来源、草稿及过期；测量数值、单位、状态 / 焦点与背景对比，按 VD-03 审定目标记录结果，不仅凭主观截图 |
| VA-10 | VIS-10 | 仅键盘完成定位与状态详情访问，错误出现不吞焦点；原生可读名称 / 状态提示、中英文长文案、缩放不遮单位或原因；后续动画关闭后状态信息仍完整 |
| VA-11 | VIS-11 | 对迁移清单核对消费者和证据；旧新并存范围清楚，字段局部通过不把结果 / 消息 / 画布标全部通过；改样式前后操作权限与结果门禁一致 |
| VA-12 | VIS-12 | 分别评审流程建模、设备、物性及结果任务：流程主画布清晰，其他任务主内容有主要空间；不以“画布必须最大”拒绝设备 / 表格布局 |

## 退出与证据

每批先完成适用语义与画板评审，再实现、验证；设计通过、代码接入和实窗通过分别记录。记录场景、消费者、数据身份、主题 / 语言、窗口或缩放、平台、截图 / 测量与失败项；按 VD-05 确定载荷与平台样本。

纯文档检查只证明组织、链接、覆盖与仓库治理。本轮未改 `.pen`、未做原生截图、主题测量或 GUI / 跨平台 smoke，全部 VA 产品验收保持待验证。真实窗口前告知，平台集中验证安排按 [当前状态](../../status/current.md)，不扩大本轮范围。
