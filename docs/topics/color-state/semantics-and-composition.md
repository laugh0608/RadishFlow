# 状态语义与组合

更新时间：2026-09-23

## 用途与状态

用途：维护状态事实来源与 V0 多维呈现的组合约束。
读者：领域状态、应用事务、诊断、Studio 与设计维护者。
不包含：领域状态机副本、接口枚举、固定色值、求解或保存策略。

父专题：[颜色与状态系统](../color-and-state-system.md)。状态：Draft / V0 待实施；具体映射接口待 VD-01 审定。以下规定显示不得丢失的语义，不替领域决定事实。

## 事实来源与独立维度

| 维度 | 事实所有者 | 呈现时不得推导的结论 |
| --- | --- | --- |
| 可编辑性 / 适用性 | 变量元数据、当前规格模式与动作能力 | 可编辑不等于必填；计算值不天然只读；灰色不决定权限 |
| 数值来源 | 参数 / 结果模型及 [工程基础](../engineering-basis-and-cases.md) | 用户指定、计算、默认、估算、继承与未知分别表达；默认不等于用户确认 |
| 完整性 / 就绪性 | 字段约束、规格与连接 / readiness | 有数字不等于就绪，可选空值不是缺项，必填空值是否阻断由所属检查决定 |
| 草稿 / 提交 | 字段草稿与正式输入事务；[单位事件](../units/input-drafts-and-interactions.md) | 有效草稿仍未提交；未完成不自动等于已提交的非法输入 |
| 保存状态 | 项目生命周期与呈现偏好所有者 | 未保存不等于非法或过期；保存成功不代表草稿已提交或结果已计算 |
| 结果时效 / 资格 | [结果专题](../results-review-diagnostics.md) 的修订和快照门禁 | 旧快照不等于当前结果；显示切换不使 current 变 stale，不能因绿灯开放输出 |
| 运行与数值结论 | 执行者及实际数值判据 | 完成、满足准则、失败、未执行、暂停分别表达；主动 hold 不等于在途暂停 |
| 问题 / 工程检查 | 领域检查产生事实，[消息模型](../runtime-messages/message-model-and-lifecycle.md) 管理身份与生命周期 | 已读不等于解决；收敛不等于守恒、适用域或设备规范全部通过 |
| 应用操作通知 | 保存 / 输出等应用服务 | 导出失败不等于求解失败，通知不污染设备问题计数 |
| 焦点 / 选择 / hover | 当前视图交互 | 只影响交互强调，不改变上述事实或门禁 |

规格模式切换先通过正式事务，再更新来源与可编辑性，不能靠改字色切换规格。检查严重程度、是否阻断及可恢复性由领域提供，颜色不得把所有 warning 当阻断或把所有灰色当禁用。问题聚合、去重和恢复按消息专题消费同一身份，V0 不新增第二套计数或日志扫描规则。

## V0 状态叠加规则

呈现按维度保留信息，不用一个总颜色覆盖全部状态。下表规定冲突时的信息保护顺序和分工；具体像素、图标形状与槽位由 R1 / VD-02 评审。

| 层 / 通道 | 承载内容 | 与其他状态并存时的规则 |
| --- | --- | --- |
| 内容与解释 | 数值或空值、单位、来源、结果时效 | 始终保留单位与来源解释；无资格数值按结果领域规则隐藏 / 限制，不为展示状态擅自开放 |
| 编辑与草稿 | 可编辑底 / 边框、草稿标记、只读原因 | 有效草稿不冒充已提交；只读不遮错误原因，禁用不移除诊断入口 |
| 诊断 | 独立图标、验证区 / 轮廓、短原因与定位 | 活动阻断 / 错误 / 警告可发现，不能被来源色、成功底、hover 或选择覆盖；保留问题所属范围 |
| 交互 | 焦点环、选择外框、hover 强调 | 焦点仍可识别，不能复用同一边框把错误擦掉；冲突时为两者保留不同通道 |
| 汇总与应用状态 | 运行摘要、活动问题计数、保存 / 输出状态 | 对应同一对象 / 工况 / 修订与作用域；不以历史最高日志级别给全局重染色 |

空间不足时，优先保留内容解释、焦点可见性和活动诊断的可发现入口；其他来源 / 草稿 / 时效等维度可用紧凑文字或详情展开，但不能消失。多个活动诊断在同一紧凑槽位中可以突出最严重者，同时保留其余数量 / 详情入口；严重程度排序与阻断性消费领域事实，不自行定义。摘要数量和身份仍由消息专题提供。

| 必须评审的组合 | 预期表达 |
| --- | --- |
| 用户指定 + 可编辑 + 字段错误 + 焦点 | 来源 / 输入单位可读，错误有原因，焦点另可辨；不靠变红把来源改成未知 |
| 有效草稿 + 旧的已提交值 | 明确当前编辑尚未提交；不把“解析成功”标成设备已就绪 |
| 未完成 / 非法草稿 + 显示单位切换 | 保留文本解释及草稿类别，遵循单位事件表，不因换显示色变成合法输入 |
| 当前结果 + 呈现设置待保存 | 结果仍 current，保存提示属于偏好；不显示“需重算” |
| 已求解 + 适用性警告 | 显示作用域明确的“已求解”和警告入口，不暗示全部工程检查通过 |
| 历史成功 + 当前输入已变化 | 当前投影显示 stale / 待重算，历史成功仅在历史范围出现，不沿用绿色成功徽章冒充当前 |
| 只读计算值 + 过期 + 警告 + 选中 | 只读原因、时效和活动问题均可发现；选择不抹诊断，数值可见性服从结果门禁 |
| hold / 实际暂停 + 无活动问题 | 中性状态并注明执行能力；不凭黄色表达暂停，不伪造执行者尚不支持的暂停状态 |
| 当前完整求解成功 + 导出失败 | 求解与应用输出分开说明；本次终止性求解错误则不能同时称本次完整成功 |
| 历史已恢复错误 + 当前无该问题 | 历史保留失败和恢复，当前不继续挂该错误；过滤历史不改变当前问题 |

若输入事实出现不可能的组合（例如同次终止失败却标本次完整成功），呈现层应暴露来源 / 身份不一致供定位，不擅自挑绿色、降级错误或“修复”领域状态；结果资格仍以权威门禁为准。具体不一致反馈与来源同步接口在 VD-01 审定。
