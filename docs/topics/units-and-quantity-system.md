读者：维护 Core、变量元数据、Studio、存储、自动化与结果输出的协作者。
不包含：子专题规则副本、完整行业单位目录、尚未实施的 schema 或完整报告系统。

- 状态：Active / U1 已实现；U2-I1 / I2 项目格式、呈现保存与个人默认已实现，I3 数值会话 / 事务已接通，原生交互和 U3 待实现；U4 按真实需求扩展。
- 关联：[现有单位参考](../reference/units-and-conventions.md)、[颜色与状态](color-and-state-system.md)、[消息](runtime-messages-and-diagnostics.md)、[结果](results-review-diagnostics.md)、[存储](project-lifecycle-storage.md)。

## 目标与当前基础

2026-09-16 确认单位系统为核心基础能力。核心数值保持 SI；GUI、变量树、CLI、导出、报告及未来 Agent 共用量与单位定义及转换方法。支持固定显示单位下切换显示并换算数值，也支持输入时临时选择单位、提交后回到显示单位。

当前 SI 字段、正式输入事务和变量描述保持。U1 新增 `rf-types::units`，变量浏览元数据改为引用量类型并派生规范单位；GUI 浏览器和 CLI 标签消费该目录。其他 Inspector / 结果表的既有 SI 标签在 U2 / U3 逐步接入，不声称全界面已支持切换。CLI v1 / v2 仍只接受对应字段的 SI 数值，JSON 字段和数值解释均不变。
