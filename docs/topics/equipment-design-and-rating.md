# 设备设计与性能校核

更新时间：2026-09-16

## 用途与状态

用途：定义流程模拟之外的设备工程主线，统一初步选型、设计、校核、流程关联及动态复用边界。
读者：维护设备模型、物性、求解、工程数据、Studio 和报告的协作者。
不包含：已交付的设备设计能力声明、完整机械规范、制造认证、供应商数据库或所有行业设备。

- 层级：一级轨道；上位规划：[模拟平台](../architecture/simulation-platform.md)。
- 子专题：[气液分离器尺寸与校核](equipment/separator-sizing-and-rating.md)、[换热器设计与校核](equipment/heat-exchanger-design-and-rating.md)。
- 状态：Draft / 方向已确认 / 按 P3 工程切片推进，不以 P5 / P6 动态和瞬态全部完成为前提。

## 目标与当前基础

用户可独立计算设备，也可从流程选中设备并引用某一工况，推荐尺寸或检查已有设备的能力。参考 HYSYS 类设备选型体验和 [Aspen EDR](https://www.aspentech.com/en/products/engineering/aspen-exchanger-design-and-rating) 的热工 / 水力设计校核方向；不声称复现商业软件内部算法或达到相同覆盖面。

现有 Flash Drum 是指定 TP 下的相分配单元；Heater / Cooler 是目标温压调节单元。它们尚无严格设备几何、选型或换热器设计能力，物性和焓限制见 [当前模型](../thermo/mvp-model.md)。新设备专题扩展产品目标，旧专题继续管理已实现单元，不能改写历史验收结论。

## 任务分类与用户路径

| 任务 | 输入 | 输出 |
| --- | --- | --- |
| 工艺计算 | 进料、操作条件、规格 | 出口状态、相分配、热负荷等 |
| 初步选型 / 尺寸估算 | 工况、方法、结构选择、准则与裕量 | 候选尺寸、控制条件、适用范围及假设 |
| 详细设计 | 工艺目标、结构和工程约束 | 满足要求的几何与性能候选方案 |
| 性能校核 | 已有设备几何、工况与准则 | 性能、限制因素、余量及不满足项 |

用户路径：选择任务→独立输入或关联流程工况→补齐所需物性 / 几何 / 准则→检查规格→计算→比较候选与依据→显式采纳→保存并输出设备计算记录。缺少上下文、超适用域或不支持的结构应在具体字段 / 条件处说明，不生成貌似完整的推荐。

首版聚焦气液分离器初步尺寸与选定类型换热器的基础热工任务。三相分离、详细塔器、振动 / 疲劳、完整机械强度、压力容器规范、材料合规及制造认证分别待专业切片，不从流程收敛或热工达标推导其合格。

## 数据、命令与数值边界

- 独立计算和流程内调用复用同一设备模型、物性、单位和规格语义；独立模式不要求用户先画一张流程图。
- 工况输入、已采纳几何 / 规格、方法与设计准则、候选结果和已保存计算记录分别有明确所有权；具体持久化类型在实施前确定。
- 引用流程结果时记录源工程 / 对象 / 修订 / 快照 / 工况身份。上游输入变化后关联计算标为过期，重算或显式解除关联，不静默使用旧结果。
- 推荐结果不自动变成工程输入。采纳通过正式命令和事务记录，支持撤销；重新推荐不覆盖用户已采纳的方案。
- 设备计算给出方法 / 版本、物性来源、关键假设、适用范围、残差和约束结果。裕量由用户确认并可追溯，不藏在经验默认值里。
- 流程耦合分为只读工况评估和影响流程的设备模型两类。若几何改变压降、传热或出口，必须通过正式模型重算；出现循环耦合时遵守对应收敛契约，不能单向回填后宣称整体收敛。
- 动态模型可以复用已确认几何、容积和传热面积，但操作液位、有效积存、壁体热容、初值等需另行补充；不以总几何容积冒充工作持液量。

UI 提供独立设备任务和流程对象上下文入口，汇集输入、推荐方案、校核和计算依据；复杂设备内容可进入主工作区，不强迫装入窄检查器。导航与页面布局交由 [UI 重设计](../architecture/studio-ui-topic-plan.md)。导出复用结果与单位系统；完整报告模板分期交付。

## 阶段与退出标准

| 阶段 | 主要工作 | 退出标准 |
| --- | --- | --- |
| E0 定义首个工程场景 | 明确设备类型、工况、方法、数据、物性依赖、独立基准和结果级别 | 场景有真实消费者；假设与准则可审查；不把演示物性当工程依据 |
| E1 首个独立设备任务 | 按子专题实现最小真实计算、规格检查与结果 | 独立输入→计算→依据→保存 / 输出闭环；成功及不适用路径有验证 |
| E2 流程关联与采纳 | 引用工况、候选比较、写入几何、撤销、过期检查 | 独立与流程模式同条件一致；采纳和回滚正确，上游变更无旧结果误用 |
| E3 设计 / 校核深化 | 按设备增加多工况、结构细节、压降 / 传热和约束搜索 | 专业方法、适用域、独立对照及失败诊断齐全，不以功能数量代替准确性 |
| E4 动态及其他设备复用 | 复用几何并补齐动态条件；按需求扩展设备库 | 输入完整性、模型版本与跨任务结果语义明确；各模型独立验收 |

各子专题不要求同步达到同一阶段。分离器所需可靠密度 / 相流量与换热器所需焓 / 传热 / 输运性质按具体方法建设；设备任务不必等待整个物性库、所有求解策略或完整动态系统。

## 验证与后续

模型验证与工作流验证分开：前者包含独立手算或公开基准、适用域、物料 / 能量收支及关键约束；后者包含单位切换、缺项、不可行方案、源结果过期、采纳 / Undo / Redo、保存重开、GUI / CLI 一致性。独立基准须记录原公式 / 数据来源及使用许可，不直接移植外部项目实现。

涉及核心模型和跨层数据时运行定向及仓库基线；界面与平台按当前状态要求验证。不因本轮文档确认变更现有项目 schema、引入求解器依赖或注册 COM。

下一步：单位与规格基础之后，按 E0 选择首个可验证设备场景；优先评估气液分离器初步尺寸，换热器按能量闭环依赖推进。
