# 单位输出与跨端一致性

更新时间：2026-09-23

## 用途与状态

用途：维护结果、复制 / 导出与自动化消费者的表示一致性，以及输出验收场景。
读者：结果界面、CLI / API、输出、消息与测试维护者。
不包含：完整报告、带单位新协议或上下文换算已经实现的声明。

父专题：[单位系统](../units-and-quantity-system.md)。状态：Draft / U3 待实现；U1 已接通变量浏览和 CLI 的规范单位标签，当前 CLI v1 / v2 数值仍为 SI。

## 消费与输出约束

| 消费者 | 转换与身份边界 |
| --- | --- |
| Inspector / 变量浏览 / 结果表 | 共用目录、量语义和有效显示选择；同一量、SI 值和格式设置产生一致表示，不在控件复制公式 |
| 已有复制与文本导出 | 先遵守当前结果门禁，再转换；单位、基准及结果身份明确。显式输出选择优先，否则捕获本次项目单位集，不在输出中途随界面偏好漂移 |
| CLI v1 / v2 | 保持已有 SI 数字、JSON 字段和规范 unit 标签；不随 GUI 单位集改变数值解释 |
| 未来带单位 API / 自动化 | 写入带稳定单位身份，读取带单位与基准；兼容扩展或版本化在 UD-07 决定，不能只替换 JSON 数字而沿用 SI 字段口径 |
| 未来录制 / 回放与报告 | 保存足以复现的单位身份及必要上下文；不依赖录制时界面偏好，模板不私存系数；范围随对应能力推进 |
| 消息、条件观察与图例 | 共用量 / 单位转换；显示不更改物理阈值、触发条件或结果身份；消息不从显示文本反推工程值 |

结果资格由 [结果专题](../results-review-diagnostics.md) 决定：stale / missing 仍拒绝当前正式输出，不借单位转换开放旧结果或调试中间值；表示转换不重算物性。格式精度不等于核心精度，跨消费者比较需同一量、基准、有效单位、格式和快照，不能只比较字符串。

输出任务捕获配置的时点、视图覆盖是否作为显式输出选择、格式与小数点规则、错误回执及协议扩展见 UD-07。完整报告与 API 单位输入不是 U3 退出的默认前置。

[运行条件 N4](../runtime-messages/run-control-and-watch-conditions.md#监视条件与运行控制) 的阈值与观察值复用规范 SI 转换，保留用户输入单位解释；缺上下文、非有限与不兼容需明确拒绝，不能解释为条件未满足。V1—V4 的图例和阈值消费方式归结果可视化；U4 逐项提供上下文能力，不默认已支持质量 / 摩尔或标准体积换算。

## 输出验收场景

目录场景见 [转换验收](catalog-and-conversion.md#目录与转换验收场景)，保存场景见 [偏好验收](unit-sets-and-persistence.md#单位集与保存验收场景)，输入场景见 [交互验收](input-drafts-and-interactions.md#交互验收场景)。本表只维护可观察预期，状态和证据见 [追踪表](requirements-traceability.md)。

| 场景 | 要求 | 操作与独立预期 |
| --- | --- | --- |
| UA-13 | UNIT-13 | 同一当前快照 `300 K`、`100000 Pa`、`1 mol/s` 以一致格式在结果表、变量浏览、复制 / 文本导出呈现 `26.85 °C`、`1 bar`、`3.6 kmol/h`；输出捕获后切 UI 单位不改变该任务选择 |
| UA-14 | UNIT-14 | 输入更改导致 stale、无快照为 missing，两者切单位后仍拒绝当前正式输出；转换失败不生成带错误标签的成功产物；导出失败只影响应用操作状态 |
| UA-15 | UNIT-15 | 旧 CLI 请求 / 响应数值始终 SI；未来新协议与回放分别用相同单位 / 上下文得到等价 SI；消息阈值切显示单位不改条件。后续消费者按其阶段验收，不冒充 U3 已交付 |

## 分阶段验证

U1 已有代码与历史测试证据，但本轮只整理文档；U2 / U3 需贯通输入→切换→提交→运行→输出→保存重开及失败路径。各切片实施前审定数据集、精度与平台范围，验证通过后才回填状态。GUI 等价输入、撤销重做、当前结果身份和偏好独立保存须一起观察，不能以换算单元测试代替真实交互验收。
