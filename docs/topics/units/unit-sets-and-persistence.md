## 显示偏好所有权与兼容设计（U2 待实现）

U1 确定以下边界，具体 DTO、版本迁移和交互在 U2 审定 / 实现；当前不新增持久化字段或空状态模块。

| 状态 | 所有者与持久化方向 | 生效规则 |
| --- | --- | --- |
| 项目显示单位集 | 项目呈现配置；拟与 document 并列随工程文件保存，独立于 flowsheet 输入及求解修订 | 保存量 ID → 单位 ID 和格式选择，不保存转换系数；不是机器专属布局 sidecar |
| 个人默认 | 应用偏好 | 仅初始化新工程的项目显示配置；不覆盖已打开工程，也不让旧工程随机器偏好漂移 |
| 临时输入单位 | 字段草稿 | 与原始文本一起保留到提交 / 取消，不改变项目显示单位；提交转换为 SI 后回到有效显示单位 |
| 临时显示覆盖 | 当前视图的显式呈现状态 | 仅在用户明确选择时覆盖该视图的项目默认；不进入求解输入，首版不承诺逐字段持久化 |
| 输出单位选择 | 输出任务配置 | 显式选择优先，否则捕获本次项目单位集；模板不自行定义系数，完整报告配置以后落地 |

有效显示为“明确的视图覆盖，否则项目单位集”；不叠加个人偏好作隐藏 fallback。旧工程没有呈现配置时按完整 SI 集解释，显式选用其他集后再保存；未知单位 ID / 不兼容量要提示并保留原信息，不能静默替换成 SI。具体旧版本读取和往返策略在 U2 格式变更前验证。

显示偏好变更有独立的保存脏标记，复用项目安全保存流程，不调用物理输入命令、不增加计算修订、不使快照过期。定义中的系数属于代码版本；工程只引用稳定身份，后续定义变化需兼容策略，不允许同名单位悄悄改变含义。

## 单位集解析与编辑边界

单位集引用目录中稳定量 / 单位身份；名称和本地化符号不能作为键。一个有效项目单位集必须为适用量给出可解释的显示选择；内置集范围、自定义集是否首版开放、格式与精度选项、部分配置如何校验由 UD-01 审定。可解析和可支持是不同条件，需上下文但当前不支持的单位不得列成可用转换选项。

改变个人默认不批量改写现有工程。项目默认和视图覆盖需要明确作用范围与恢复入口；覆盖的生命周期、持久化以及输出是否显式继承某视图不能从界面位置猜测，分别见 UD-01、UD-07。项目单位集变更不修改来源标签、计算模式或快照身份。

## 保存、失败与撤销

呈现偏好可以独立要求保存，但不进入物理输入历史。安全写入、替换失败和工程关闭的共用流程归 [项目生命周期](../project-lifecycle-storage.md)；本文只拥有单位配置的保存语义。

- 保存成功后才能按实际写入内容更新保存基线；失败时保留待保存偏好和可重试路径，不因失败使求解结果 stale。
- 有字段草稿时执行保存不能静默提交、丢弃草稿或写入显示数字替代 SI；事件约束见 [UE-12](input-drafts-and-interactions.md#u2-事件表)。保存是否要求先处理草稿由 UD-03 审定，不承诺草稿会随工程恢复。
- 撤销物理输入走正式历史；呈现偏好是否进入独立历史及快捷键路由由 UD-04 审定，不能为了支持 Undo 而伪造物理输入变化。
- 旧工程无配置采用完整 SI 集；未知 / 不兼容 ID 的保留、可编辑性、读写往返及旧版本读取策略须在 UD-02 给出证据，再修改文件格式。不能仅通过打开时回退 SI 掩盖数据丢失。

验收为 [UNIT-05—07 / UA-05—07](requirements-traceability.md)，未实施的兼容路径保持待验证。

## U2 单位集与保存候选方案（待审定）

2026-09-23 提出 UD-01 / UD-02 推荐，用于实现前范围和兼容评审；本节不冻结 JSON 键名、Rust DTO 或实际版本号，也未修改文件格式。上方所有权仍有效，以下首版取舍须经审定后进入正式规则。

### 首版单位集与适用范围

| 决策 | 推荐范围 | 取舍 |
| --- | --- | --- |
| 内置集 | 完整 SI 集；另提供工程集，以 °C / bar / kmol/h 显示绝对温度 / 绝对压力 / 摩尔流量，其他 U1 量默认规范单位 | 只选已有目录单位，不以工程集之名隐含表压、质量流量或标准体积基准 |
| 项目自定义 | 允许逐量修改 U1 七类量的显示选择；不做命名单位集库、导入导出或自定义转换公式 | 保存完整有效选择，不只保存预设名称，避免后续预设更改让旧项目漂移 |
| 个人默认 | 允许将当前完整选择显式设为“新工程默认”；旧工程无配置仍用 SI | 应用偏好独立保存；个人默认写入失败只影响该操作，不回滚已应用项目配置 |
| 视图覆盖 | 首批 Inspector 提供显式“仅本视图”按量覆盖及“跟随项目”恢复；同一项目 / Inspector 上下文内跨对象保持，关闭该视图或工程结束后失效 | 不进入项目文件、不产生项目保存脏标记；切对象不创建逐字段持久化副本。恢复失效范围需在 R1 标清 |
| 格式 | 首版保持共享数值格式，不开放各控件私有精度设置；编辑精度按 UD-06 管理 | 可配置有效位数与本地化输出格式继续由 UD-01 / UD-07 后续细化，不把该扩展伪装完成 |
| 首批字段 | 现有可编辑流股的温度 / 压力 / 总摩尔流量，以及 Feed、Heater / Cooler、Mixer、Valve、Flash 已支持的温压参数 | 名称和组成编辑行为保持；物理约束从现有字段消费，其他结果表 / 复制 / 导出的转换按 U3 接入，不声称单位集已覆盖所有页面 |

单位集配置可覆盖完整目录，消费者接入分批进行。U2 设置页需要明确首批生效范围；其他尚未接入消费者仍使用自身明确的 SI 标签，不能把 U3 提前宣称为已完成。视图覆盖如何被 U3 输出显式采用留在 UD-07。

### 保存基线与格式建议

静态核对发现：[项目 DTO](../../../crates/rf-store/src/project.rs) 当前外层版本为 1，只有 kind、schema_version 和 document；内层 metadata 校验也共用这个版本常量。[加载 / 保存驱动](../../../apps/radishflow-studio/src/document_lifecycle_driver.rs) 只装载 / 组装 document，保存成功后记录工程 revision；[WorkspaceState](../../../crates/rf-ui/src/state.rs) 尚无独立呈现保存基线。只改写盘函数不足以保存 / 恢复单位集，应用加载与保存状态投影也必须接入。

推荐把当前呈现配置与最近成功保存的呈现配置作为独立状态比较，工程的既有 revision 脏判断保持。项目总体待保存为两者任一变化；草稿数量另外显示，不混入“已经保存的内容”。单位设置应用、撤销和恢复为已保存选择均不推进求解修订；写盘成功才同时更新对应保存基线，失败不清脏、不改快照资格，原数据保护与恢复证据沿用安全保存契约。另存为复用安全写入，成功才改变路径与基线。

格式推荐采用新外层项目版本（候选 v2）保存与 document 并列的呈现块；块中保存稳定量 / 单位 ID 的完整选择，不保存系数、临时输入单位、视图覆盖、草稿或历史栈。缺失配置只在明确旧版本迁移时补完整 SI；新格式缺项、重复键、不兼容组合或未知 ID 不能静默补值。具体字段、格式选项如何演进、外层和 metadata 版本常量如何分离仍须 DTO 评审，不能把所有内层数据机械升级或更改工程数值语义。

推荐升级外层版本的原因是：[JSON 版本分派](../../../crates/rf-store/src/json.rs) 当前会拒绝较新外层版本，但同版本数据会进入现有强类型反序列化。按当前 DTO 的静态结构推断，在旧版本信封中加可选单位字段不能保证旧程序重存时保留它；未做旧二进制实测，不能宣称向后无损。

| 文件路径 | 推荐处理与可观察结果 | 必须补的证据 |
| --- | --- | --- |
| 读取现有 v1 | 在内存补完整 SI，不因打开而产生呈现脏标记，不自动写回磁盘 | SI 数值、工程身份与原文件不变；旧工程不受个人默认影响 |
| 通过新版保存 | 新写入采用新版本；从 v1 首次保存前说明格式升级及旧版不可读，允许另存为保留原件 | 明确升级提示、取消不写盘；安全保存失败保留原数据 / 恢复证据及可重试状态 |
| 旧程序读取新版 | 利用版本门禁明确拒绝，不让旧程序读入后丢掉单位配置再保存 | 用旧读取器 / 固定 fixture 验证拒绝，不能只跑新版本自读 |
| 未知单位 / 新格式缺项 / 不兼容量 | 首版推荐拒绝此次项目装载，提示量 / 单位身份，保留原文件与当前工作区；不自动改 SI 或部分装载 | 无原地重写；不能在“保留原信息”名义下把未知数据存成已知配置 |
| 可保留未知配置的只读打开 | 作为替代方案，需要独立的原始数据保留、只读状态与另存兼容设计，本轮不默认纳入 | 若选择此方案，补读取 / 往返 / 编辑禁用验收后再实施 |

该建议会改变新版文件的旧程序可读性，属于 UD-02 的明确批准项。只读设计评审不升级任何用户工程。应用默认偏好另按 [现有偏好 DTO](../../../crates/rf-store/src/studio_preferences.rs) 评审版本与旧值保留，不因项目版本变化顺带重置最近项目记录。

### 保存验收细化

- UA-05：七类量配置完整、两个预设可解释；修改项目选择不改变个人默认；个人默认只影响新建；Inspector 覆盖跨对象保持、结束视图后跟随项目。
- UA-06：呈现 A→B→撤销回 A 后与保存基线一致；工程 revision / 快照全程不变。工程和呈现同时有变更时保存成功更新两者基线，有草稿仍显示未提交数量；注入写盘失败后两者均保持待保存。
- UA-07：旧 v1 打开不写盘、首次新版保存说明升级；新格式未知 ID / 缺项 / 较新版本拒绝且原件未变；旧读取器拒绝新版本。该候选批准前，不能把“拒绝装载”替换进正式验收预期。
