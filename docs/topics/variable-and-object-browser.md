# 统一变量与对象浏览器

更新时间：2026-10-24

## 用途与状态

用途：定义工程分类浏览、变量树、路径访问及共享读写入口的产品目标、领域边界、实施切片与验收。
读者：负责 Studio、变量 / 动作描述、CLI、后续自动化及工程对象扩展的设计与开发者。
不包含：最终 UI 画板、冻结的路径语法 / DTO / ABI、COM 激活方式、完整脚本运行时或新的项目格式。

- 层级：二级功能；父专题为 [Studio 主工作流](studio-main-workflow.md)，跨端边界遵循 [统一对外 API](../architecture/simulation-platform.md#对象变量与动作树)。暂不拆子专题。
- 状态：Draft / 2026-09-28 规划方向已确认。现有 B3-1—B3-5 为复用基础；本文 VB0—VB3 的新增设计与实现尚未完成。
- 定位：一个变量工作区提供工程视图与变量树视图，共用稳定身份、领域描述、查询和正式命令。覆盖所有公开工程变量与动作，逐步纳入非画布对象。
- 顺序：U2-I1—I4 与 U3 首批已接通，I5 按确认节点补验；VB0 纳入 R0 / R1 及 G0 关系设计，VB1 衔接 U3，VB2 依赖 U2 编辑闭环，VB3 按 P2 与领域能力扩展。依赖和排期入口见 [路线图](../radishflow-mvp-roadmap.md#变量与对象浏览器的配套切片)。

## 用户路径与交互

### 一个工作区、两种视图

目标为可停靠的浏览器，允许展开为完整工作页，与流程图和 Inspector 对照使用。具体位置、尺寸、窄窗口降级与入口由 R0 / R1 局部评审确定，现有模态窗口在替代路径验收前保持可用。

- 工程视图：按实际能力组织组分与物性、单元、流股、设计基础、工况与运行结果；同类对象可表格对照。分类为导航投影，不复制可变工程数据。
- 变量树视图：按对象、输入 / 结果、变量或集合展开，支持路径跳转、复制稳定引用及元数据详情。动作与变量区分呈现，标明参数、条件、撤销能力与调用结果。
- 两视图共享变量选择和读取上下文；过滤和折叠只改变呈现，不改变对象身份、结果资格或全局问题计数。
- 工程、模型、工况和运行结果上下文保持可见；当前仅显示已支持的文档 / 快照上下文，不提前提供无功能选择器。

候选布局为“上下文与搜索 + 分类 / 树 + 变量表 + 可展开详情”。主表优先显示对象、变量、值、单位和状态；路径、说明、约束、来源及关联置于详情。身份始终可查看，不要求普通用户记忆底层字段名。

### 核心操作

1. 搜索名称、变量、量或路径，筛选输入 / 结果、未指定 / 异常、对象类别和关注项。搜索结果保留对象、分区与上下文，避免同名变量混淆。
2. 从变量定位画布对象和 Inspector 字段；Inspector 提供反向打开变量的入口。非画布对象定位到其正式页面；没有目标时明确说明，不伪造画布节点。
3. 对同类对象查看相同字段；缺字段、未指定、无结果与不支持分别呈现，不用零填表。
4. 单值输入在支持后就地编辑；组成、互斥规格等组合通过专用编辑器提交。输出保持只读。
5. 将变量加入关注列表，在修改和运行后审阅；保存的是稳定引用及显示偏好，不是第二份值。关注列表不等于 N4 的条件监视或求解控制。
6. 分别复制数值、带单位数值、可读路径和稳定引用。结果复制 / 导出遵守 [当前结果门禁](results-review-diagnostics.md)，旧值不作为当前数值输出。

键盘可完成展开、搜索、选择、定位和编辑；右键操作同时提供可见入口。异步刷新不抢焦点或覆盖草稿，导航和切换上下文按 U2 的草稿规则处理，不自动提交或丢弃。浏览器切换不隐式运行、保存或创建对象。

### 代表性验收路径

在受支持流程中搜索所有出口温度→区分显式输入与结果→定位 H-101 的温度字段→按指定单位修改→Undo / Redo→正式运行→审阅关注变量→保存重开后恢复引用。H-101 仅为示例显示名；引用实际绑定稳定身份。VB1 先验收只读子路径，完整编辑路径在 VB2 验收。

## 身份、路径和读取上下文

### 稳定身份与路径

保留现有类型化身份；路径层负责解析和展示，解析结果通过同一查询 / 命令入口访问。人类导航路径和可持久引用明确区分。以下仅示意，尚未冻结协议：

```text
可读导航：主流程 / 单元 / H-101 / 输入 / 出口温度
稳定路径：/documents/{document_id}/units/{unit_id}/inputs/outlet_temperature
```

- 重命名、分类调整和视图切换不能破坏稳定引用；名称路径有歧义时返回候选或错误，不能任选一个。跨文档引用、删除对象与字段消失分别返回结构化失败。
- 路径编解码需明确版本、保留字符 / Unicode 转义、大小写、集合索引、别名与弃用策略；Rust `Debug` 输出、显示文案及单位符号不能作为稳定协议。
- 输入和结果是不同变量分区；设备端口中的流股入口引用同一流股，不复制对象。分类树、流程图与求解执行树不要求同构。
- 保存重开须能解析同一身份；另存为、复制模型、导入、删除后重建及跨工程回放的身份规则需要与生命周期专题审定。录制重放通过创建回执绑定新身份，不硬编码原案例 ID。

### 变量定义与取值上下文

变量定义描述“什么量、属于谁、如何访问”；取值带明确文档 / 修订及快照来源。后续扩展到模型、工况和运行身份时，外部调用显式指定上下文，界面选择只能生成请求，不能成为隐藏的取值前提。

AF4a 的工作区查询通过会话与输入身份检查快照归属，revision 本身不证明归属；旧的独立文档 / 快照构造仍要求调用者提供同一工作区数据。历史运行不能被当前文档值覆盖，跨工况不能串值，过期结果不降级成 current 返回。

当前 `ValueState` 与 `ValueSource` 保持；未来来源、输入合法性、结果时效、诊断严重度和可编辑性按各自语义组合，不扩大成互斥的大状态枚举。未指定、缺失、过期、不支持、未分析及数值零分别表达，草稿不冒充已提交工程值。

## 描述、数据与命令边界

### 共享描述与领域所有权

| 描述内容 | 责任与用途 |
| --- | --- |
| 稳定字段标识、名称、说明、分类 | 所属领域 / 应用描述提供；用于枚举、搜索、导航和协议映射 |
| 类型、形状、命名坐标轴 | 按模型实际需求扩展布尔、枚举、数组、组成、级数、时间和空间坐标 |
| 量类型、规范单位与基准 | 引用统一单位目录；质量 / 摩尔、表压等上下文转换遵守单位专题 |
| 可写条件、约束、选项与拒绝原因 | 由领域提供；“变量可写”与当前规格方案允许指定分别判断 |
| 值来源、修订、快照 / 运行身份 | 输入与结果所有者提供；浏览器不推断求解成功或工程可信度 |
| 导航目标、对象引用与动作描述 | 应用层映射正式页面 / 字段和命令；执行时重验实时条件 |

浏览器是领域数据的访问投影，不建立全局可变变量仓库，不把任意内部字段反射为公共写入入口。Core、对象模型、求解与结果各自拥有数据和行为；Rust Core 不承担 COM 语义。

现有变量枚举部分借用了 Inspector 字段函数。新增消费者时，应按实际复用将稳定字段描述归入共享应用描述，让 Inspector、浏览器与 CLI 消费；不为此预建插件注册框架或新增空 crate。公共传输 DTO 与 Rust 内部模型分离，已有 CLI v1 / v2 不被静默改义。

目录枚举、搜索和读取可分别执行；大集合按需展开、分页或范围读取，时空结果提供带坐标和来源的切片。只读界面按文档修订与结果身份刷新，避免每帧枚举并取出全部值；缓存仅为可失效投影。分页 / 订阅期间的修订一致性和资源限额随 VB3 消费者定义。

### 写入与批量事务

统一路径为：解析身份与上下文→单位 / 基准转换→修订、草稿及权限检查→类型与领域校验→正式输入事务→历史与结果旧化→返回回执。具体检查顺序复用既有应用入口，不在 GUI 或传输适配器复制领域约束。

- 单变量写入复用 B3-2 与 U2 数值会话。原始文本、临时输入单位、精度、冲突和提交 / 取消由同一草稿机制管理，不新增浏览器私有工程草稿。
- `write_via` / 元数据不能替代执行时检查；非 GUI 写入仍受 `PendingDrafts` 和 `expected_revision` 保护，不通过清草稿绕过冲突。
- 结果始终只读。改变显示单位只改变呈现，不增加物理输入修订或旧化结果；既有 CLI 继续按 SI 解释数值。
- 跨对象批量编辑须先建立正式批量事务：在一致输入上校验整个集合，一次提交、一次文档修订和一次撤销；任一失败不部分落地，失败定位具体变量。组合约束校验最终集合，不能靠顺序单写临时非法中间值。
- 多个副作用不同的动作不混成变量批量事务；Run、Save、创建、连接分别使用正式动作契约。现有 CLI 有序步骤的逐步回执 / 失败停止语义继续保持，不追溯改为整体原子执行。
- 相同有效输入继续返回无变化回执，不制造历史或旧化结果；真正修改后沿用统一失效与运行触发策略，不在循环写入时逐字段意外求解。

## 范围与非目标

纳入：工程分类和变量树、搜索 / 筛选、稳定引用、字段级定位、同类对象表格、关注列表、受控编辑、描述完善及后续跨端发现 / 访问。

本轮不实现代码、重画 `.pen` 或冻结公开接口。首版不要求完整多模型 / 工况、时间序列 / 空间场、COM 注册、脚本语言、插件运行时、AI、远端服务、任意模型反射或求解器内部状态编辑。未实现能力不注册成功占位动作；能力扩展按所属领域与下表切片推进。
