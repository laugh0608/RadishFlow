# 消息系统场景与验收矩阵

更新时间：2026-09-23

## 用途与状态

用途：把需求变成可观察、可回归的行为场景。
读者：实现者、测试者、设计评审者和后续协作者。
不包含：虚构的测试通过证据、独立需求状态副本与数值准确性证明。

- 层级：二级功能；父专题为 [运行、消息与诊断](../runtime-messages-and-diagnostics.md)。
- 状态：Draft / 规划方向已确认，细化决策与实现尚待所属切片；现有能力不能直接算作新增要求已验收。
- 范围、依赖与 N0—N5 顺序以父专题为准；[需求追踪表](requirements-traceability.md) 记录要求、阶段、场景及证据。

## 当前基础与验证策略

现有测试与实窗记录继续作为回归基础；下表均是新增规划的待执行场景，不是通过记录。每次实施从追踪表选择涉及要求，先补适用输入与独立预期，再记录实际命令 / 测试位置、平台、日期与结果。

单元测试验证身份、状态、单位及规则；集成测试验证事件、事务、保存和消费者边界；Pencil 评审信息层级，已告知的原生实窗验证焦点、滚动、键盘和读屏。无后台 / 循环 / 动态能力时，只能验证已具备层级，不以模拟事件测试宣称真实求解集成完成。

## 消息与生命周期

| 场景 / 要求 | 操作与输入 | 可观察预期 |
| --- | --- | --- |
| S-01 / MSG-01 | 分别触发输入缺项、求解错误与导出失败 | 各归正确作用域，导出失败不改变设备求解结论 |
| S-02 / MSG-02 | 重复检查同一对象，再检查同名不同身份对象并切换语言 | 同范围去重；不同目标不误合并；代码及定位不随文案改变 |
| S-03 / MSG-03 | 修正输入、Undo / Redo、删除并同名重建，再重检 | 重检前不假定通过；通过后解决；历史目标不误跳转 |
| S-04 / MSG-04 | 制造可恢复局部失败再恢复，并对照终止性失败 | 仅真实恢复退出活动问题；历史保留；致命失败不降级；后续未执行可辨 |
| S-05 / MSG-05 | 隐藏 / 已读根问题并查看全局、画布、模块和列表 | 计数按身份一致且门禁不解除；仅有依赖证据才标根因 |
| S-06 / MSG-06 | 对照完成带警告、收敛但设备检查失败、求解失败与暂停 | 运行、数值、结果、检查分开；无错误不等于检查通过；中间值不进入正式结果 |

## 执行过程

| 场景 / 要求 | 操作与输入 | 可观察预期 |
| --- | --- | --- |
| S-07 / MSG-07 | 执行三步并使第二步失败，另触发重试 | 开始、失败和终止可追踪；第三步未执行；重试有独立尝试身份 |
| S-08 / MSG-08 | 查看重复模块、嵌套循环和黑箱记录，注入重复 / 迟到 / 缺段事件 | 树来自执行计划；重复不误计、缺段可见；不伪造黑箱内部或并行总序 |
| S-09 / MSG-09 | 查看不同量纲、内外层及未采集残差 | 层级、缩放、容差、试算 / 接受值清楚；缺值不补零；趋势有判据 |
| S-10 / MSG-10 | 用已记录规模的密集 trace、慢视图、容量满和记录失败运行 | 内存有界；截断可见；关键证据不静默丢失；显示级别不能补回未采集数据 |

## 运行控制与条件

| 场景 / 要求 | 操作与输入 | 可观察预期 |
| --- | --- | --- |
| S-11 / MSG-11 | 在模块及不可中断第三方调用中请求暂停 | 先显示请求中，到执行者安全边界确认后才暂停；不支持能力明确 |
| S-12 / MSG-12 | 暂停后单步 / 继续，重复取消并与自然完成竞争 | 步骤边界明确；终态不倒退；取消不冒充数值失败或完整结果 |
| S-13 / MSG-13 | 暂停后改输入或切换工程，并交付旧运行迟到事件 / 结果；另测关闭 | 旧运行不能直接继续或覆盖当前；关闭按明确策略处理而非假定调用已终止 |
| S-14 / MSG-14 | 配置出口 > 180 °C，切换 K 显示并用等价输入运行 | SI 语义相同，原单位可解释，触发点不随显示单位或舍入改变 |
| S-15 / MSG-15 | 删除目标、使用不兼容量 / 缺上下文单位，运行产生 NaN / 缺值 | 显式拒绝或按已定策略停用 / 停止；不按 false 静默继续无监视运行 |
| S-16 / MSG-16 | 构造阈值往复、多个同时命中和试算 / 接受值差异，隐藏日志并降采样 | 按规则求值与重新武装；显示与采集采样不漏触发；监视不暗改物理值 |
| S-17 / MSG-17 | 对照墙钟、仿真时刻、结果回放与兼容 / 不兼容检查点 | 真实时间与回放分开；观察记录不宣称可重启；黑箱恢复能力明确 |

## 交互与多处联动

| 场景 / 要求 | 操作与输入 | 可观察预期 |
| --- | --- | --- |
| S-18 / MSG-18 | 从全局 / 画布 / 模块进入同一问题并切换窄窗口 | 同源定位、计数一致；问题与过程可关联；旧标签迁移无重复事实 |
| S-19 / MSG-19 | 保留非法单位草稿时定位另一字段，再执行已过期修复建议 | 草稿不暗丢 / 暗提交；定位不修改；修复重验修订并支持正式撤销 |
| S-20 / MSG-20 | 编辑时收到新消息，向上浏览后持续接收 trace | 不抢焦点、不毁草稿、不移动点击目标；新事件提示可回最新；不跟随不暂停运行 |
| S-21 / MSG-21 | 用键盘、读屏、非彩色表达访问右键对应动作及长本地化消息 | 存在可见 / 键盘入口；不逐迭代抢读；颜色外仍辨识；详情按需展开 |
| S-22 / MSG-22 | 分别打开未检查、无问题、未采集、过滤无匹配及历史目标已删除的视图 | 各状态可区分，当前 / 历史范围可见；不可定位解释明确 |

## 存储与消费者

| 场景 / 要求 | 操作与输入 | 可观察预期 |
| --- | --- | --- |
| S-23 / MSG-23 | 写入大量事件、改变筛选、修改规则后保存并重开 | 不会每条消息增加工程修订或 Undo；规则保存独立策略明确；运行捕获规则版本 |
| S-24 / MSG-24 | 读取无规则旧工程、未知规则版本、失效目标并往返保存 | 旧行为保持；未知信息保留并说明不可用；无静默忽略或覆盖 |
| S-25 / MSG-25 | 重开含历史 / 截断证据工程，模拟落盘失败及保留清理 | 当前重新检查、不自动继续内存运行；记录完整性可见；清理遵守范围 |
| S-26 / MSG-26 | 在 GUI / CLI 查询同一范围，回归现有 v1 / v2；未来再测订阅缺口 | 同源语义；最终 JSON 与 SI 保持；新增流 / 控制独立版本化；Core 不引入 COM |
| S-27 / MSG-27 | 导出含旧运行、调试值、技术详情与截断记录的选定范围 | 单位、身份与完整性明确；不混入正式结果；无关敏感数据不附带；复现限制可辨 |

## 开发者诊断与模型验证

规范见 [开发者诊断](developer-diagnostics-and-model-validation.md)。下列场景随所列能力逐段验证，模型 / 数值基准由领域提供独立预期。

| 场景 / 要求 | 操作与输入 | 可观察预期 |
| --- | --- | --- |
| S-28 / MSG-28 | 对同一物性终止失败切换工程 / 数值详情，再隐藏开发信息 | 身份、严重程度与阻断不变；工程影响可见；详细信息不重复计问题 |
| S-29 / MSG-29 | 独立模块测试返回非有限输出或违反端口契约，另测同对象重试和黑箱调用 | 领域产生契约诊断；调用 / 尝试身份清楚；独立任务无伪造流程对象；黑箱内部不支持可辨 |
| S-30 / MSG-30 | 对有已知导数的案例显式运行检查，另测相边界 / 缺导数、关闭探针及载荷超限 | 变量、固定条件、方法与扰动尺度可查；不直接判定边界差异是实现错误；检查隔离正式运行，开销与截断可见 |
| S-31 / MSG-31 | 同一物性调用切换参数版本、组分顺序 / 相定义及参考态，并缺失部分来源 | 调用保存当时有效上下文；差异与未知来源明确，历史不被新参数覆盖 |
| S-32 / MSG-32 | 新旧参数分别运行拟合和独立验证案例，含拟合改善但验证退化、失败及不兼容基准 | 指标公式 / 权重 / 数据集与输入差异可查；退化和失败不删除；不兼容部分不形成改善结论；同实现自证不算独立验证 |
| S-33 / MSG-33 | 按选定实验导出诊断包，缺专有包 / 外部数据，另测截断或删减载荷 | 清单与实际内容对应、缺失及复现限制可见；不自动上传或混入凭据，不把调试值作正式结果或承诺检查点恢复 |

## 切片评审与退出

- N0：审阅分类、状态组合、工作台与消息 / 单位 / 颜色叠加路径，保留待决策清单；不把画板通过当作产品实现。
- N1—N5：逐项执行本切片适用场景；跨阶段要求拆记已覆盖与未覆盖部分，不能因前半段通过把整项标为已验证。
- 旧 SI CLI、当前结果门禁、输入事务 / Undo、保存重开和既有诊断恢复按影响面回归。新增风险和平台差异必须留证据。
- D-10：各切片实施前选择测试载荷、可接受时延 / 内存指标、平台及辅助技术，建立可重复条件；本规划不编造已测性能数字。
- 新缺陷先关联既有要求 / 场景；确属新行为时新增编号。回归失败或语义改变应撤销相应验证结论，保留历史证据。
