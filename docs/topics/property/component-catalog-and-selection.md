# 组分目录与工程选择

父专题为[物性系统](../property-basis-and-components.md#子专题关系)。本期覆盖 Studio 现有受控目录和已打开工程中的组分，供用户确定建模所用组分、核对哪些流股仍引用它们。

## 数据与交互

- 目录中的稳定 ID 和名称取自现有包描述，甲烷与乙烷的分子式沿用 Studio 展示元数据。工程文件定义的只读组分保留自己的 ID、名称和可选分子式。
- 在「物性 → 项目组分」输入名称、分子式或稳定 ID 的片段即可筛选，忽略首尾空白和大小写。完整匹配优先，输入 `Ethane` 时乙烷排在同样含有该片段的 Methane 前面。空查询显示全部候选，无匹配时可以修改或清空查询。筛选属于窗口状态，选包、建模就绪和工程修订只受实际输入变更影响。
- 选择与移除复用现有工程命令。重复选择同一 ID 不产生新修订。工程内流股的总组成只要包含该 ID，即使摩尔分数为零，也算引用。物性页列出流股名和稳定 ID，移除命令在执行时复核同一组引用。检查读取已提交的工程输入，运行结果由独立快照拥有。
- 未引用的内置组分可移除、撤销和重做。保存重开恢复物性包 ID、工程组分和流股组成。二元烃包始终装载自己的完整数据，工程可先选其中一个组分继续编辑。显式求解时仍按包要求校验流股组成。文件定义的只读组分保持原有编辑权限。

## 求解前核对进料组成

Studio 对已应用的无回路序贯计划读取工程显式选中的本地求值包清单。拓扑有效时，按每台 Feed 的出口绑定，将已提交的总组成键与清单中的稳定 ID 逐项核对。显式零分数算作已提供。清单沿用当前会话给出的 ID，兼容使用自定义 ID 的旧示例。Mixer 和 Flash 的输出模板由单元计算填充，留给执行阶段处理。

「流程运行」显示有差异的进料股数。点击后，「当前问题」逐股列出流股名、稳定 ID、包 ID、必需组分，以及缺少或包外的 ID。可定位到这股进料的组成，也可前往工程组分。以纯甲烷为例，先在工程选择乙烷，再对需要纯甲烷的每一股进料显式添加零分数乙烷。仅修改工程选择时，两股进料原有的组成均保留。

检查随工程修订、已应用计划或包清单变化刷新。拓扑失效或无法取得所选包的组分清单时，检查范围显示原因。项目内单相显热模型、回流及方程计划沿用各自的检查。本项提示允许继续编辑、保存和显式运行，求解器仍按实际装载的物性系统验证输入。执行时若 Feed 的组成校验失败，步骤诊断携带该进料出口的流股 ID。Studio 可定位到其组成，CLI v3 和 C ABI 返回同一流股身份。[跨端复核](../../devlogs/2026-11/2026-W48.md#2026-11-25-af4--af5-进料组成错误定位修复)
