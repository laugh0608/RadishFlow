# 组分目录与工程选择

父专题为[物性系统](../property-basis-and-components.md#子专题关系)。本期覆盖 Studio 现有受控目录和已打开工程中的组分，供用户确定建模所用组分、核对哪些流股仍引用它们。

## 数据与交互

- 目录中的稳定 ID 和名称取自现有包描述，甲烷与乙烷的分子式沿用 Studio 展示元数据。工程文件定义的只读组分保留自己的 ID、名称和可选分子式。
- 在「物性 → 项目组分」输入名称、分子式或稳定 ID 的片段即可筛选，忽略首尾空白和大小写。完整匹配优先，输入 `Ethane` 时乙烷排在同样含有该片段的 Methane 前面。空查询显示全部候选，无匹配时可以修改或清空查询。筛选属于窗口状态，选包、建模就绪和工程修订只受实际输入变更影响。
- 选择与移除复用现有工程命令。重复选择同一 ID 不产生新修订。工程内流股的总组成只要包含该 ID，即使摩尔分数为零，也算引用。物性页列出流股名和稳定 ID，移除命令在执行时复核同一组引用。检查读取已提交的工程输入，运行结果由独立快照拥有。
- 未引用的内置组分可移除、撤销和重做。保存重开恢复物性包 ID、工程组分和流股组成。二元烃包始终装载自己的完整数据，工程可先选其中一个组分继续编辑。显式求解时仍按包要求校验流股组成。文件定义的只读组分保持原有编辑权限。

## 验收
