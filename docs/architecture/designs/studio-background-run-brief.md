## 入口与信息层级

应用内最多一个活动计算，流程与设备共享配额。各页面在导航下保留同源运行摘要：**工程 / 任务 / 工况、阶段、查看运行、取消指定任务**。无活动任务时收起进行中摘要；终态留在既有消息 / 运行日志中，不弹出抢焦点的成功对话框。

“查看运行”展开并定位既有运行日志区域的任务详情，不改变当前页面、所选设备行或编辑草稿；不新建第二套日志面板，不在本切片重排全部底部标签。详情显示输入来源、阶段、已用时、可得进度和最近最多 8 次紧凑记录；技术标识和诊断码仅在详情需要时展开，主界面不展示 worker、epoch 或 Ready 等实现词。

流程原 Run / F5 改为提交操作，接收后立即呈现准备状态，不能把 Accepted 显示成已完成。同目标运行中按钮显示“运行中”并禁用；经快捷键 / 命令重复触发时，在原有前置检查通过后定位现有任务，不新建、不取消、不排队。其他目标占用时禁用计算入口，并在相邻文案说明占用对象，提供查看 / 取消该任务入口。

## 状态与文案

| 真实事实 | 用户可见状态 | 可执行动作与边界 |
| --- | --- | --- |
| 准备资源、等待开始许可 | 准备运行 / 准备校核 | 允许取消；不显示未知总数、百分比或 ETA |
| 流程数值执行 | 流程运行中；正在计算 V-101；已完成 2 / 3 个单元 | 查看、取消、编辑、保存、切页；进度按完整单元，不解释为耗时百分比 |
| 设备数值执行 | V-202 / 工况 B 正在校核，或正在计算尺寸 | 只报告阶段、对象和用时，不虚构内部迭代进度 |
| 已接受取消、执行尚未退出 | 正在取消；等待当前调用返回 | 取消按钮不可重复提交；其他计算仍不可开始；可以编辑 / 保存 |
| 任务收尾且取消先被处理 | 已取消；本次未更新结果 | 查看记录；资格允许时重新运行。若实际已成功返回，详情仍写“计算已返回，结果未接收” |
| 当前完成且资格有效 | 完成；结果已更新 | 按领域原规则查看 / 输出，不另造全局成功结论 |
| 当前准备或数值失败 | 运行未开始 / 计算失败；简短原因 | 查看详情与真实可用的修正入口；原因未解决时不诱导无效重试 |
| 当前任务基础设施故障 | 运行异常结束；本次未更新结果 | 输入保留，显示诊断详情；确认收尾后才允许新提交 |
| 输入、授权或会话已失效的完成 | 未更新；输入已改变 / 工程已切换等 | 仅留旧运行记录，不把当前工程改为失败、不弹跨工程错误框 |

建议取消请求接受 **5 秒后**追加“等待当前调用返回”说明，并持续显示已用时；这只是反馈阈值，不承诺 5 秒内停止，也不增加强杀按钮。终态仅在线程确实结束并完成接收 / 丢弃后呈现。

## 编辑、自动运行与结果

流程模式使用“自动运行：开启 / 关闭”说明 Active / Hold，保留“恢复运行”的现有命令含义。关闭自动运行只阻挡后续触发，不暂停或取消在途任务。用户显式取消流程时同时转 Hold；设备取消不改变流程模式。

正式输入提交、Undo / Redo、改包 / 组分或清结果使旧任务失效并协作取消；一般草稿不改变已捕获输入。输入变化造成的内部取消保留模式：Active 只保留同一工作区最新输入的自动运行意图，旧任务退出后重新检查草稿、readiness、选包与授权，最多接受一次最新请求。Busy 的手动请求不进入队列，设备计算也不自动接续；清结果本身不制造一次重算，沿用原触发资格。

运行结果与执行阶段分别呈现。“上次结果”只按原有资格展示，不能算作本次取消的产物。流程输入未变时既有有效结果可保留；输入改变后的旧结果保持过期。当前有效失败沿用已有清当前结果 / Hold 行为；旧输入的失败不影响当前状态。

设备矩阵的活动任务始终绑定原 task / case；选中 C 时取消按钮仍写明 B。修改不相关 C 不取消 B，共同几何、依赖来源或 B 的正式输入改变才按领域资格失效；删除目标不把结果转给其他行。计算阶段单列，Current / Failed / Stale / Missing 仍由设备领域确定。

Sizing 重算开始时旧候选资格与 Rating 不同：前者保留原候选直到完成替换，后者立即撤销旧行结果资格。本稿不统一改写这两种领域规则。**正在重算源对象的采纳 / 单行导出入口暂时禁用**，仍可查看带“上次结果”标签的证据；取消后按领域资格重验，不能把已失效的 Rating 结果恢复为 Current。不相关有效行仍可输出；矩阵继续允许覆盖不完整的审阅输出，准确列出各行原有状态 / 原因，不写入部分计算结果或新增协议状态。输出 / 采纳等待期间仍重验捕获身份、草稿与单位。

## 切换、只读与退出

普通切页、切设备行、显示单位 / 语言及另存为不取消任务。新建 / 打开必须先走既有草稿、脏改、格式和读取流程；取消选择或读取失败保留原会话与任务，取消不显示为错误。真正替换工程或进入只读覆盖时才撤销旧任务并请求取消；旧任务未退出仍占计算槽，摘要明确其原工程。新工程可编辑、保存和浏览，但不继承原工程自动运行意图；只读返回也不复活旧任务。

最后拥有窗口关闭或应用退出分为两段：

1. **原有离开保护**：有草稿或脏改时先完成原确认、保存及格式保护；初始焦点为取消关闭，失败保留工程和在途任务。工程干净时不额外增加保存确认。
2. **等待收尾**：确认离开后拒绝新提交、请求取消，显示“正在结束运行；收尾完成后关闭”。界面继续响应；唯一恢复动作是“取消退出，返回编辑”。任务已结束时直接完成关闭，不强制闪现等待弹窗。

等待时返回编辑不撤回已发送的计算取消，也不自动重新运行。此前选择“放弃并关闭”只是离开意图，实际输入和草稿保留到最终离开；返回时撤销放弃意图，下一次关闭重新确认。成功写盘的保存不因返回而回滚。等待时不开放其他工程编辑命令，返回编辑后再修改，避免绕过已确认的保存检查。

同一文档仍有其他拥有窗口时，只关一个观察窗口不取消共享任务。确认退出后不可中断调用永久不返回，仍无法保证优雅退出；没有强制停止、倒计时或假成功。原生 picker 可能阻塞事件循环，AF3c 不据此宣称解决 AF1。

## 键盘、窄区与提示

- F5 保持页面语义：流程 Run 或当前设备工况计算；草稿与模态前置检查不绕过。Shift+F5 保留已有流程恢复运行，不复用为取消。新增取消动作从可见按钮和命令面板进入，并绑定发起时精确任务；任务已完成时不取消后来任务。
- Tab / Shift+Tab 可达查看、取消与返回编辑；Enter / Space 只激活当前焦点。Escape 在普通工作区不取消计算，在关闭确认中取消离开，在退出等待中返回编辑。确认按键不透传到下一层界面。
- 400 px 面板状态与动作纵排，长任务名、英文自然换行；正文可纵向滚动，关键目标与取消入口不被省略。非颜色表达使用图标与短文本，蓝色焦点边框不承载计算结论。
- 新进度和终态不夺焦点、不清草稿；查看运行后返回原入口。200% 画板仅验证字体放大布局，不代替真实 OS 缩放、读屏与平台键盘验收。
