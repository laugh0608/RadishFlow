## 任务入口与内容层级

候选功能域为项目 / 开始、物性、流程、设备、运行 / 研究、结果 / 输出、工具 / 设置。最终导航命名和层数在 R0 评审，不按候选清单机械增加同等权重的菜单。

- 工程设计基础与工况矩阵优先纳入 R0：公共条件、来源、假设和覆盖由项目上下文管理，设备结果关联具体工况。
- Home 让用户选择任务，也能返回已有工程上下文。独立设备任务不要求先建流程图；是否作为项目内案例持久化由设备与存储专题决定。
- 物性工作区拥有数据与方法入口，流程和设备引用同一上下文；不复制两套组分选择器状态。
- 流程工作区以画布为中心，对象详情可跳入相关设备任务，再回到原对象。
- 设备工作区区分初步尺寸、设计和校核；显示工况来源、规格、几何、候选与计算依据，主内容可用表格和结构示意。
- 运行 / 研究与结果空间按能力渐进展开，当前同步计算不显示不存在的后台能力，未来动态实验和多工况不混成普通日志。
- 设置提供单位集和显示偏好的入口；字段附近允许临时输入单位。当前没有 AI 功能，不设计聊天占位主入口。

## 字段交互的评审样例

首批温压流量画板以 [UA-08—12 交互场景](../../topics/units/input-drafts-and-interactions.md#交互验收场景) 为输入，逐项标注 [UE-01—13 事件](../../topics/units/input-drafts-and-interactions.md#u2-事件表)：本次输入单位与有效显示单位的作用范围、四类草稿状态、提交 / 取消 / 撤销、焦点及保存。以输入 `300 K`、显示 `26.85 °C` 为代表，但不能只画成功路径。

偏好归属见 [单位集与呈现保存](../../topics/units/unit-sets-and-persistence.md)。已接受的触发 / 历史规则以 UE 表为准，具体接口和剩余决策见 [UD 追踪](../../topics/units/requirements-traceability.md#待决策清单)；画板只表达行为，不反向冻结 Rust API 或项目 schema。

规格提示先解释“缺少什么 / 为何冲突”，再给定位或正式动作；分析未支持时显示未分析 / 不支持，不能画成零自由度。建议尚未执行、执行成功、执行条件已变化分别呈现。

设备候选与已采纳几何有不同状态。推荐结果显示工况与方法，采纳操作说明改动；源工况过期后显示重新计算入口，不能保留可直接应用的旧建议。尺寸估算与详细设计级别在结果中可辨识。

工程工况的评审样例：共同冷却水条件被多个设备引用，用户修改后能看到受影响案例；显式覆盖的值与公共值可区分。同一换热器几何在一个工况满足、另一个工况失败时，汇总必须显示失败及控制条件，不能只保留成功行。设备位号与内部 ID 分开，更改位号不破坏案例 / 结果引用。

项目所有者已认可本轮问题入口、定位、失效与重检方案，并授权先补齐 Pencil 局部画板与静态复核，通过后接线及验收；A2 暂不实现，I5 沿用既定补验节点与发布限制。以下为 D-07 局部方案，承接 [A1-I1 报告](../../topics/modeling-assistance-and-specifications.md#a1-i1-实现与验收状态2026-10-11) 与 [N1 首批生命周期](../../topics/runtime-messages/message-model-and-lifecycle.md#n1-随-a1-的首批细化)，不重评全局 R0，不把方案状态标成产品实现。

### 入口与布局

推荐复用底部诊断区域，以“当前问题”为主视图；Run Panel 摘要增加同源的“当前问题 · 2”入口。点击只展开 / 聚焦问题区，不切换工程、运行或提交字段。沿用现有运行记录 / 诊断详情入口，不再增加一套独立日志工作台或第七个底部标签，也不重排其余页面。首批不增加画布徽章计数系统；定位时复用对象 / 连接选择高亮。

宽窗口保留“画布 + Inspector”，底部按“问题列表 / 选中项依据”分栏。问题行包含类型图标、对象 / 字段、短原因和当前性；选中行只读详情，显式“定位字段 / 定位端口”才跳转。详情显示已提交值、约束依据与来源，技术规则 / SI 证据可展开。示例为 Heater 缺出口 T 与 Mixer 出口 1.30 bar 高于两入口 1.50 / 1.20 bar；最低来源标在 inlet_b / Feed B，不能用输出模板充当依据。

窄窗口先压缩非必要摘要，再切成“当前问题 / 对象字段”单列页；定位进入字段页，“返回当前问题”恢复选中行与列表位置。字段和原因换行，不依赖悬停；画布仍可回到原上下文。候选稿以约 700 逻辑像素的内容宽度演示切换，最终阈值以 egui 文本与控件实测为准，不能冻结为不同 DPI 下的物理像素。候选只展示局部区域，不代表完整窗口导航重排。

### 定位与焦点

| 目标 | 行为 | 保护边界 |
| --- | --- | --- |
| 单元参数 | 选中单元，打开现有模块设置，滚动并聚焦确切字段 | 定位不代填、不应用、不截压；字段缺值时仍保持缺值 |
| 流股 T/P/F/z | 打开现有流股 Inspector，定位标量或组分行 | 保留显示单位与临时输入单位；依据正文按当前显示单位呈现，检查仍为 SI |
| 端口 / 连接 | 选中相关单元 / 连接，打开现有连接入口，强调对应端口 | 不自动连接、补出口或删除流股；多目标时列出清楚的端口入口 |
| 工程组分 / 空流程 | 进入现有物性组分位置 / 组件库 | 不替用户添加组分或放置单元 |
| 已删除的原目标 | 定位禁用并写明“原目标已删除” | 按稳定 ID 重验；同名重建不承接旧问题，不把删除称为检查通过 |

同工程的只读定位按 UE-13 保留全部草稿，不因点选问题弹出丢弃确认。工程级“草稿 · n”入口持续可见；返回原对象时，非法原文、输入单位、编辑会话和焦点规则继续由 U2 管理。只有后续用户发起删除、工程 Undo / Redo、切工程等会清除草稿的真实操作，才走已有离开保护。问题自动更新不抢焦点、不自动选择首条、不打断组合输入；对象字段的错误提示与焦点分别显示。

键盘顺序为入口→列表行→详情 / 定位→目标字段；Tab / Shift+Tab 遵循原生顺序，Enter / Space 只激活聚焦动作。定位后提供可见返回入口；重检保留问题选择和滚动锚点，原问题消失时只播报汇总并把显式返回路径保留，不把焦点强制移入下一错误。双语、长名称、放大字体及非颜色表达必须在 I2 产品验收中复核。

### 失效与重检呈现

时效、规则覆盖和求解结果分开表达，不能折成一个绿灯：

| 显示状态 | 触发与内容 | 下一步 / 限制 |
| --- | --- | --- |
| 尚未检查 | 初次打开 / 切换工程，尚无当前报告 | 自动同步检查；不能短暂显示“0 问题” |
| 当前 · n 项 | 报告与工程会话 / 输入修订匹配 | 可看依据、定位；计数来自同一问题集合，不按 UI 副本相加 |
| 草稿 n 项 | 只编辑原文，正式输入未变 | 正式报告仍为当前；提示检查基于已提交输入，草稿不被算成已解决 |
| 待重检 · 上次 n 项 | 正式输入 / 拓扑修改、工程 Undo / Redo，或相关模型 / 物性上下文变化 | 先失效再检查；上次行与数值加“上次依据 r…”标记，不以旧数量冒充当前数量 |
| 检查中 | 当前检查尚未返回 | 保留旧依据，避免重复发起；短同步检查可直接更新，不强制显示动画或人为等待 |
| 检查未完成 | 检查过程异常，未取得完整当前报告 | 保留上次依据及失败原因，提供“重新检查”；不发布空数组冒充已解决 |
| 当前 · 部分范围未检查 | 已得到合法报告，但拓扑或必需输入阻断依赖规则 | 当前已知问题照常显示；另列未检查范围及原因。缺上游必需 P 不写成单纯“待运行检查” |
| 待运行检查 | 报告明确给出需要实际执行上下文的关系检查 | 仅该范围待执行，不视为通过；依然由正式求解检查，不靠模板或 stale 结果补齐 |
| 本批局部检查未发现问题 | 当前同范围检查完成且无问题 | 明列结构自由度 / 数值可解性未分析；不称“全流程可解”，不恢复旧结果输出资格 |
| 目标已移除 | 稳定目标已被删除，旧条目退出当前投影 | 本会话变化中可说明移除；同名新对象按新身份检查，不能继承旧跳转 |

触发采用 I1 已批准的同步整份文档检查：初次打开 / 切换、正式提交、连接 / 删除、工程 Undo / Redo 后自动重检，另保留“重新检查”按钮，运行前再确认当前报告。未提交草稿、语言 / 显示单位、焦点和面板收起不使输入报告失效。收到不匹配工程 / 会话 / 修订 / 检查代次的结果时丢弃该结果，不能覆写新工程；I2 接线后由 GUI 工作区持有会话，具体实现见文末产品证据。

只在相同检查范围已明确完成时把未再出现的条目标为已解决；未检查的依赖范围保留未确认状态。默认列表展示当前问题，已解决变化只给克制的本会话摘要，不新建 N2 历史库。对象名 / 数值 / 本地化文案不作为问题键。运行诊断只有结构化规则、稳定目标和来源能确证同一事实时才关联；无法对应时保留来源，禁止按文案猜测合并。

“重新检查”只读正式输入，不运行物性、不修改修订 / Undo，也不暗中运行求解。运行按钮沿用已有授权、草稿和运行门禁；不能因预检发现压力冲突，就把原 `failed / solver.step.parameter` 改成新增 `blocked`。结果栏独立显示“旧快照已过期 / 当前输入尚未运行”，局部检查通过后仍需真实求解才产生 current 结果。

### 入口、预览与跨入口一致性

推荐在当前问题的既有详情区增加动作行：“定位输入”“预览：归一组成 / 创建出口 / 接受连接”“本修订忽略”。点击问题只查看依据，点击预览在详情区原位展开，返回保留原问题选择与滚动；不增加顶层页面、底部标签或常驻浮层。未生成可执行候选时保留定位，并说明现有候选能力范围。A1 尚有未检查范围时继续展示覆盖限制。

建议区列出同一会话的可用推荐；画布候选标记仍用于定位上下文，显式打开同一份预览。独立候选无确切 A1 关联时只在建议区 / 画布出现，不伪造问题行或增加阻断计数。忽略、恢复、过期及提交回执共用 I1 状态，三个入口不能各自缓存可执行动作。

| 预览类型 | 必须展示 | 明确接受后的变化 |
| --- | --- | --- |
| 正式组成归一 | 流股、逐组分已提交值 / 新值、原总和、`xᵢ / Σx`、文档修订 | 全组成一次事务、一条 Undo；不应用 Inspector 草稿 |
| 创建出口 | 新流股名称 / 稳定目标、源端口、实际创建的 T/P/F/z 全部初值 | 创建并绑定一次提交。Feed 显示 298.15 K、101325 Pa、1 mol/s、已选组分等分；空组成明确为空；模板不补单元显式参数 |
| 已有连接 | 准确源流股 / 端口及目标端口、现有规则的生成条件 | 只执行选中连接；竞争候选随修订失效，无自动串接。排序不代表工程意图 |

用户已审阅的载荷不得在点击接受时静默更新。执行条件或载荷变化后禁用旧接受，要求重新生成并查看预览。按钮采用“接受并归一”“接受并创建”“接受此连接”，不使用模糊的“修复全部”。数值依据继续使用 SI，显示单位遵循 U2；换单位不生成新语义动作。技术规则版本 / 目标 ID 可折叠，工程值与影响必须直接可见。

### 窄区域、草稿与键盘

窄区域沿用 A1 单列问题 / 字段页；预览在问题详情内纵向展开，表格按字段换行，不另弹出宽对话框。定位后仍只有一个字段编辑器；“返回原问题与预览”恢复上下文。若离开期间正式修订改变，只能恢复已失效预览的说明，不能复活接受按钮。处理草稿沿用已有显式应用 / 舍弃操作，返回后重新生成预览；导航本身保留非法原文、输入单位与编辑代次。

Tab / Shift+Tab 保持原生焦点遍历，Enter / Space 只激活当前聚焦动作；打开预览的按键不能透传成接受。Escape 关闭局部预览并返回依据，不自动忽略、不丢草稿。原画布的 Tab 快捷接受建议改为在无文本输入焦点且候选上下文明确时打开预览，原本应遍历焦点的 Tab 保持原义；不得直接写入。接受必须再次显式触发预览中的按钮，且消耗当帧激活事件。该快捷行为变更已获认可，产品接线须按此验收。
