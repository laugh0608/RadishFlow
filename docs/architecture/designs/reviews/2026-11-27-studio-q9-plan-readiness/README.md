# Q9 已应用计划的就绪提示

「稳态运行计划」编辑器已接入所有者认可的两处变化。在「应用计划」操作下方，就绪提示写明「已应用计划」和计划修订。已应用计划含块外撕裂时，提示就地列出流股 ID、源端口和汇端口。流程结果显示自己的资格与运行来源。[打开交互稿](boards.html)

## 用同一条绑定走查

打开时，运行 #1 已发布 10 股，草稿刚把第二条绑定改为 `s-bleed`。顶部「第二条草稿流股」用来模拟在 Studio 移除第二条绑定并添加另一条。稿中的运行按钮和 F5 按既有回执演示结果。可在顶部切换语言、字号或重置工况。

| 操作 | 在就绪提示中应读到 | 流程结果 |
| --- | --- | --- |
| 保留初始错误草稿 | 已应用计划修订 0 的拓扑与绑定已就绪。上方绑定行标明草稿未应用 | Current，运行 #1 的 10 股仍可审阅。[中文预览](draft-zh.png) |
| 点击「应用计划」，先停在运行前 | 已应用计划修订 1 未就绪。原因是撕裂流股位于循环块外，流股为 `s-bleed`，源端口为 `splitter-1.outlet_b`，汇端口为 `mixer-3.inlet_a` | Stale，须重跑。[中文预览](applied-zh.png) |
| 将第二条草稿流股改回 `s-recycle-2`，先不应用 | 编辑区显示正确草稿，提示仍指出修订 1 中的 `s-bleed`。按 F5 仍运行已应用的错误计划 | 重跑前为 Stale，运行 #2 在装配阶段结束，结果为 Failed。[400 px 英文大字号预览](repair-draft-en-400.png) |
| 点击「恢复已保存」，再运行 | 恢复后为修订 2，拓扑与绑定已就绪，错误流股及端口从提示中消失 | 恢复时为 Stale，运行 #3 后为 Current |

## 接入依据

- 就绪提示读取已应用计划的 `validate_for(&workspace.document.flowsheet)` 及同一计划的修订。绑定编辑行读取草稿。运行资格和结果继续由既有动作及结果模型提供。[Studio 计划编辑器](../../../../../apps/radishflow-studio/src/studio_gui_shell/flow_plan.rs)
- 对本例的 `solver.partitioned.outside_tear`，使用当次检查错误上下文中的流股 ID，并与已应用撕裂配置的 `source`、`sink` 及错误所带端口核对角色。草稿可与已应用绑定不同，两条绑定也可交换顺序。仅展示当前错误能确认的目标，保留其他原因的原有诊断。[拓扑检查](../../../../../crates/rf-solver/src/flow_plan.rs) · [块外撕裂的目标构造](../../../../../crates/rf-solver/src/partitioned/plan.rs)
- CLI v4 的 `flow_plan.not_ready` 提供错误码和原因，端口角色可对照已应用的 `configuration.tears`。Studio 可直接读取上述结构化错误，运行前即可显示目标。运行后的三个定位动作仍使用现有「运行诊断」。[真实 CLI 与 macOS 实窗记录](../../../../devlogs/2026-11/2026-W48.md#2026-11-27-q9-块外撕裂)

## Studio 实窗验收

macOS Studio 在同一份 0.60／0.25 同名流股工程中完成三次运行，输入修订始终为 0。表中的截图来自原生窗口。

| 窗口操作 | 计划编辑器 | 流程结果 |
| --- | --- | --- |
| 原计划运行后，草稿换成 `s-bleed` | 上方显示待应用的绑定，下方仍是已应用修订 0、已就绪 | #1 Current，10 股。[草稿与原计划](studio-draft.png) |
| 用 Enter 应用 | 修订 1 未就绪。流股 `s-bleed`、源 `splitter-1.outlet_b`、汇 `mixer-3.inlet_a` 在运行前即可读 | Stale，旧正式流股入口收起。[已应用的块外撕裂](studio-applied.png) |
| 草稿改回 `s-recycle-2`，先不应用，再按 F5 | 修订 1 仍显示同一错误及两端口。[正确草稿与错误的已应用计划](studio-repair-draft.png) | 重跑前 Stale，#2 在装配阶段失败，实际局部调用 0 |
| 选择「恢复已保存」 | 修订 2 已就绪，错误流股和端口从提示中清除 | 仍为 Stale。[恢复后、重跑前](studio-restored.png) |
| 再按 F5 | 修订 2 已就绪 | #3 Current，发布 10 股。[重跑后](studio-rerun.png) |

Enter 应用后焦点留在已停用的「应用计划」，再按 Enter 修订仍为 1，Tab 移至「恢复已保存」。在 1080 × 889 点窗口把界面放大到 120% 后，流股、源端口和汇端口各占一行，标签和 ID 完整可读。[窄区实窗](studio-narrow.png) · [运行及验证记录](../../../../devlogs/2026-11/2026-W48.md#2026-11-27-q9-计划就绪提示实窗验收)
