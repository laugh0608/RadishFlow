## R0 局部结论

| 候选 | 操作路径 | 评审建议 |
| --- | --- | --- |
| A · 画布就地查看 | 流程图选中流股 → 查看直接上下游端点 → 按需播放方向示意 → 打开对应流程结果 | **已确认采用。** 在建模、修正连接和查看结果时均可读连接方向，结果可用时再给出对应流量和方向示意。 |
| B · 流程结果集中查看 | 流程结果选中流股 → 打开二维路径视图 → 返回结果列表 | 适合集中审阅已有结果。未运行和失败场景仍需回流程图辨认连接与断口，增加一次往返。 |

- 保留「流程图」「流程运行」「流程结果」现有一级入口。V1 放在「流程图」画布区，流股标签和选择框共用同一 `StreamId`。突出所选流股和直接两端的单元，侧区列出单元与端口。同一流程的其余连接保持可读，空端与流程边界各自显示。
- 端点定位沿现有画布定位，保留 V1 所选流股。查看运行诊断沿 R2 定位和返回，端口标记与选择轮廓能同时辨认。点「在流程结果中查看」进入当前流程的对应流股结果。按返回恢复原流股、原动作焦点、画布视口和显示单位。流股已移除时回画布并说明，换工程或重开后清除会话内的路径和返回位置。
- 当前结果范围由会话、流程、修订与快照资格决定。沿用现有结果查询、身份守卫和单位换算。播放、暂停、选中流股和定位都是呈现操作。重跑使用既有命令，工程、输入草稿和结果快照按原契约管理。

## R1 播放和结果状态

| 所选流股状态 | 画布表达 | 控件和结果 |
| --- | --- | --- |
| 当前有效，流量有限且大于零 | 默认静态箭头。用户播放后仅在所选连通流股上移动方向标记 | 显示该流股流量及运行修订，可暂停或打开流程结果。标记速度仅表达方向。 |
| 当前有效，零流量 | 保留静态连接箭头与路径端点 | 显示实际零值，播放不可用并说明原因。 |
| 过期、缺失、失败，或该流股的流量不可用 | 按当前拓扑保留静态箭头与可读原因。失败样例显示断口和入口诊断 | 播放不可用，数值区显示对应原因。结果与诊断沿原入口审阅。 |
| 用户暂停、系统减少动态效果、画布隐藏 | 保留静态箭头 | 用户暂停立即停止。系统减少动态效果时说明原因。画布隐藏时停刷，返回且同一快照仍有效时可恢复原播放状态。 |

切换流股、快照资格变化或进入系统减少动态效果时，清除播放意图。获得新结果后由用户再次播放。首片可使用既有稳定连接和当前流股的摩尔流量。显式设备、流股和诊断标记保持形状与文字可读，选中态使用独立线宽和轮廓。

## 产品接线

本片交付同一用户路径，按画布与往返、结果与播放的顺序接入。范围是 Studio 呈现与工程会话内导航。求解、持久化和导出沿用现有契约。工程数据着色、三维和动态回放沿各自专题推进。

| 接线 | 现状与实施范围 |
| --- | --- |
| 画布选择与端点 | [画布](../../../../../apps/radishflow-studio/src/studio_gui_shell/panels/canvas.rs)已有静态箭头、流股点击和查找锚点。[连接视图模型](../../../../../apps/radishflow-studio/src/studio_gui_canvas_presentation/mod.rs)已有两端单元与端口。沿用现有线段、端口标记和 `inspector.focus_stream` 路径，新增局部流股选择、直接端点轮廓和可键盘操作的端点定位。端点定位可以移动检查器焦点，V1 的流股仍按 `StreamId` 保留。终端产品流按既有边界语义显示。遇到缺端，只在现有拓扑或诊断能确证关联时挂到相应流股，无法确证时保留原端口诊断。原生几何和控件用产品现有样式，画板的折线路由作为示意。 |
| 结果与诊断往返 | [现有选择逻辑](../../../../../apps/radishflow-studio/src/studio_gui_shell/app.rs)和[结果检查器](../../../../../apps/radishflow-studio/src/studio_gui_shell/panels/runtime/results.rs)已支持按快照与流股选中结果。V1 动作进入「流程结果」并落到对应流股，返回恢复原动作、流股、视口和显示单位。诊断继续走 [R2 返回机制](../../../../../apps/radishflow-studio/src/studio_gui_shell/flow_diagnostics.rs)，按实际目标落到单元或端口。返回时目标移除或原结果已替换，则用当前画布或原诊断列表的说明接住焦点。换工程、重开同文件或关闭会话时清除返回记录和播放意图。 |
| 流量资格与播放 | [结果查询](../../../../../crates/rf-ui/src/result_query.rs)已有 `Current`、`Stale`、`Missing`、`Failed`。[结果守卫](../../../../../apps/radishflow-studio/src/result_review.rs)可校验同会话、修订与快照。按 `StreamId` 从当前快照读取原始摩尔流量，按共享单位呈现。显示单位和舍入独立于播放资格。只有当前快照的有限正流量和明确可绘制的连接方向可播放，合法流程边界用现有连接语义判定。零值照常显示，缺值、负值和非有限值保持静态并给出原因。动画仅画在所选线段上，暂停或画布隐藏时停止申请动画重绘。切换流股、快照更换或失效时清除播放意图，重新播放由用户触发。 |
| 减少动态效果 | 原生画布消费平台可取得的系统偏好，系统要求减少动态效果时立即停播。无法可靠读取偏好的平台显示静态箭头并说明。首轮在 macOS 验证偏好变化，Windows／Linux 的系统偏好和实窗结果按各平台留证。 |

最小验证覆盖原始 `5 mol/s` 与显示 `18 kmol/h` 的资格一致性、Liquid Outlet `0 mol/s`、失效及同修订新快照停播、缺失与失败、同名或删除流股、同文件重开和草稿保留。中英文 400 px／20 px 自动帧验证按钮、说明和焦点可见。macOS 代表实窗走 Feed–Heater–Flash 的 `Heated Outlet → 流程结果 → 返回`、零流量、入口断口诊断和系统减少动态效果。用代表性大流程检查关闭与不可见时的重绘，再按影响面执行 Studio 定向测试与锁定仓库基线。

### 验收结果

- 产品使用原生画布线段。对当前快照的正流量可显式播放，显示按流程结果的项目单位。无有效结果的单端流股显示空心端点。选中流股的浮层让位于 V1 控件，保留端口与诊断标记的可见性。
- macOS 27.0.1 arm64 实窗用二元烃 Feed–Heater–Flash 与 Heater 入口断开的临时副本。Heated Outlet 为 `5 mol/s`，可播放并落到流程结果的同一行，返回后回车可重开该行。Liquid Outlet 为 `0 mol/s`，播放不可用。断口可见，经过运行诊断聚焦 Heater `inlet`，两级返回后检查器、所选流股和发起动作回到 Feed 的原上下文。工程副本校验值一致。
- 自动回归覆盖中英文 400 px／20 px 控件、草稿与视口保留、同修订重跑停播、缺失和失败、删除及同文件重开。含 72 个单元和 96 条流股的自动帧核对暂停、线段被裁剪和离开画布时均停止安排动画重绘。系统减少动态效果的禁用分支通过自动检查，macOS 实窗覆盖系统偏好关闭时的播放。系统开关的原生动态切换、Windows／Linux 实窗和实际读屏待补。 [周志证据](../../../../devlogs/2026-11/2026-W46.md#2026-11-15-studio-v1-产品接线)
