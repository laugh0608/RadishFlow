# Studio H3 流程关联只读复核评审稿

2026-11-22 · 局部 R0／R1 · 项目所有者已确认主动作、单当前结果的失效时机和取消／关闭边界。设计以 `d25dec51` 的 CLI v14 和前一版独立 H3 复核画板为基线，面向从已保存的冷热两条流股复核同心套管换热器的用户。 [换热器专题](../../../../topics/equipment/heat-exchanger-design-and-rating.md#h3-流程关联-studio-只读复核) · [独立 H3 认可稿](../2026-11-21-h3-studio-review/README.md)

打开 [可编辑交互画板](boards.html)，在顶部选取样例、语言和基准字号。可操作「运行并复核当前工况」、切换工况、取消、查看依据和定位诊断。画板中的运行与取消由交互演示模拟，数值和诊断代码取自真实 CLI v14。源稿包括 [HTML](boards.html)、[交互](boards.js)、[布局补充](styles.css) 和 [CLI 证据](evidence.js)。样式沿用独立复核画板和仓库字体。

## 已确认交互

1. **打开与查看。** 沿用 Studio「打开工程」和工程只读复核入口。受支持的 v4 无回路工程列出已保存的 H3 关联工况。即使文件混有独立工况，关联界面也只列关联目标。文件里存在未知能力或方法时进入整份原文只读检查。复核视图保留原工作区。已保存的冷热侧流股身份及资格依据可先查看，新会话从待运行开始。
2. **运行与复核。** 主动作「运行并复核当前工况」使用 `h3-pure-water` 修订 `1`，在后台发起一次共享稳态运行，通过 `H3FlowReview` 用同一快照预览和复核。冷热侧卡片显示已保存的引用，实际入口温压和流量随本次结果的来源展开。开始新运行时撤销上一份结果的当前资格。可以切换工况查看输入，在途动作和当前结果仍归发起的工况。每个复核会话同一时间只有一个运行任务。
3. **完成与诊断。** 40 mol/s 显示当前结果及三项通过。50 mol/s 显示完整当前结果并标记一项超限。资格拒绝保留原诊断码，只有诊断带流股目标时出现查看侧别的动作。定位后聚焦流股引用，Escape 回到诊断动作，再按 Escape 返回原工作区。流程运行失败保留运行诊断和工况归属。
4. **取消与关闭。** 取消请求发出后显示「正在停止」，收到终态后显示「已取消」。返回工作区时解除复核视图与任务的关联，后台所有者负责回收。重开是新会话，迟到回执依据会话、工况和运行身份拒收。关闭最后一个窗口的等待沿用现有任务回收规则。

## 应用动作与状态归属

| 状态或动作 | 接线约束 |
| --- | --- |
| 只读装载、工况列表和来源 | 用同一份工程字节识别受支持的关联和创建身份。工程、任务、几何、工况及来源修订进入冻结输入。复用当前只读打开和原工作区保护。 |
| 资格及执行 | 复用 v14 的纯水资产、静态资格核对及 `H3FlowReview`。后台接线复用共享稳态执行的冻结输入、取消和结果接收契约，复核会话拥有独立运行态。使用共享工作区所有者的本地已评审资产通路。 |
| 结果、超限及失效 | 以任务／工况、复核会话和实际接收的运行快照作为资格。`Current` 与限值通过分别呈现。新运行撤销旧结果资格，切换查看保持原结果归属，工况页只显示自己有资格的数值。 |
| 显示与键盘 | 已有量类沿用工程显示单位，UA 和压降使用 W/K、Pa。窄区用纵向布局，Tab／Shift+Tab 可访问工况、动作、依据与诊断。主动作开始后焦点进入可用取消，停止与完成后恢复到可用动作。 |
