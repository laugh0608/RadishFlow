# Studio N3 单元暂停与单步

2026-11-25，v1 待评审。面向需要在稳态运行中检查单元顺序的建模用户。交互使用双进料 Mixer，运行身份与竞争规则见 [D-04 提案](../../../../topics/runtime-messages/run-control-and-watch-conditions.md#d-04-无回路稳态运行控制提案)，原生产品的退出条件见[首批验收](../../../../topics/runtime-messages/scenarios-and-acceptance.md#n3-无回路稳态首批验收)。

## 走一遍双进料 Mixer

打开[交互画板](boards.html)。上方浅色区是评审工具，「演示下一次执行器回执」可以让执行器在检查点等待，方便核对命令发出和实际停下之间的界面。下方展示拟接入 Studio 的局部控件。运行编号和读数是演示数据，数值预期取自 [N2 的 Mixer 验收](../../../../devlogs/2026-11/2026-W48.md#2026-11-25-n2-计算过程与诊断审阅)。

1. 初始结果来自运行 #20。选择「运行并在首步前暂停」，观察 #21 正在暂停；送达执行器回执后，首股前显示 0/3。普通「运行」仍可在执行中请求暂停。
2. 选择「单步（一个单元）」并送达回执，在第二股前看到 1/3。再单步一次，Mixer 前显示 2/3。此时仍可辨认旧的 5 mol/s 来自 #20；继续或单步末项并送达回执后，结果归 #21。
3. 在停点选择取消，或用评审工具模拟提交第二股为 4 mol/s。前者保留旧 Current，后者使旧结果过期。线程结束后重新运行，新输入的 Mixer 出口为 6 mol/s。
4. 切换到「第二股缺乙烷」，逐步执行至第二股失败，或在第二股执行中请求暂停再送达回执。两条路径都显示失败和 Mixer 未执行。「单相显热计划」展示仅支持取消的活动运行。

## 控件与状态

| 控件所在位置 | 产品接线与键盘语义 |
| --- | --- |
| 流程运行 | 增加独立的一次性「运行并在首步前暂停」。保留普通运行和 F5 的直接执行路径；只为适用的已应用计划提供新增入口。 |
| 活动栏 | 运行中可请求暂停；确认停点后依次可单步、继续、取消。暂停与继续按运行身份分派，放行还要匹配停点。已取消或已消费的动作不可再次触发。 |
| 计算过程与结果 | 活动停点显示编号、已完成数、下一单元；运行终态沿 N2 历史审阅。正式结果显示自己的运行编号，用户查旧记录时不将控制目标切到历史运行。 |
| 窄区与键盘 | 控件换行；Tab 按阅读顺序，Enter 激活。被操作的按钮消失时焦点回到状态，其他位置保留焦点。命令面板须捕获打开时的运行与停点，目标变化须重新选择。原型演示局部按钮，命令面板和真实窗口焦点随产品接线验收。 |
