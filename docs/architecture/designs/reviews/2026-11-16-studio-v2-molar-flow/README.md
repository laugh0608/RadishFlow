# Studio V2 流股摩尔流量图层

2026-11-16，项目所有者确认 R0／R1 首片的图层入口与色带范围。范围见[结果审阅专题](../../../../topics/results-review-diagnostics.md#可视化接下来事项)。

## 已确认决定

- R0 在现有画布工具栏设「图层」入口，默认显示连接方向，用户按需打开「摩尔流量」。图例就近呈现变量、项目显示单位、范围及运行／修订。切换图层时保留流股选择。
- R1 在单张当前快照内按 `0…max` 的 SI 摩尔流量线性着色，图例注明范围来自当前快照。切换项目显示单位时更新标签、图例端点和流股结果读数。零流量显示数值和色带低端。单流股缺值显示中性虚线及文字。多工况比较所需的共同标尺按后续使用场景评审。
- 当前结果资格沿用共享查询，画板中的运行号和修订位于同一工程上下文，实际读取仍须校验会话、修订和执行计划。过期、缺失或运行失败时撤下数值及色带，保留静态拓扑和对应原因。诊断保留独立图标和定位入口，选中状态有单独的轮廓。

## Studio 接线范围

- Studio 工具栏使用两个可用键盘操作的选项。图层选择属于当前工程会话的呈现状态，重开或新建工程时回到「连接方向」。
- 线身和箭头按当前摩尔流量着色。利用现有流股标签空位和提示显示数值，短线段仍可从流股选择区或检查结果查看数值。诊断标记、定位和返回沿用现有机制。
- 图例位于画布上缘，取当前快照所有有效流股的最大值，零范围显示单色。过期、缺失或失败时显示原因并采用中性连接线。
