# S-09 固定温压回流残差局部交互稿

2026-11-26 · R1 已获项目所有者认可 · 原版对照基线 `0c29c863`

[打开交互稿](boards.html)。使用顶部「评审设置」切换工况、语言、字号和上下文。「运行中」工况另有检查点选择，可停在瞬时阶段读数。设置栏用于操作画板；下方为 Studio 的局部界面。

本稿供求解、Studio 与验收维护者评审固定温压单撕裂回流的运行条、成功块和失败诊断。数据来自 [D-03 两份 CLI v4 报告](../../../../devlogs/2026-11/2026-W48.md#2026-11-26-d-03-固定温压回流报告对照)。产品接线范围与验收读数分别归[字段专题](../../../../topics/runtime-messages/execution-trace-and-convergence.md#s-09-界面改动范围)及[S-09 验收矩阵](../../../../topics/runtime-messages/scenarios-and-acceptance.md#s-09-固定温压单撕裂回流)。

## 评审路径

| 在画板上的操作 | 应能读到的结论 |
| --- | --- |
| 选「0.90 · 运行中」，在顶部查看「复核 1 开始」，再切到「复核 1 完成」 | 开始时正在执行独立复核 1，最近完成的是迭代 229。完成后最近样本才换成复核 1。在「迭代 1 开始」显示尚无已完成求值。0.99 的迭代 500 开始时可对照迭代 499。 |
| 选「0.90 · 收敛」，查看块 4 | 迭代 228 的绝对残差略高于容差，缩放残差已达标。迭代 229 首次同时达标并成为候选，复核 1 通过。每项判据邻接量值、单位、容差与文字结论。 |
| 展开末次组分，再展开乙烷原始 SI 精度 | 常规读数均为 25.2 mol/s。精确假设值为 25.19999999916261，返回值为 25.199999999246348；报告差值为 +8.373746140932781e-11 mol/s。尺度为 5 mol/s。 |
| 点「查看正式流股」，再返回 | 目标行属于当前来源，生产端返回总流量为 44.99999999865418 mol/s。返回后焦点回到原动作。上方切到「重跑中 · 原结果仍为 Current」可继续核对原来源；输入修改、切工程或重跑回执获接收时，旧详情关闭。 |
| 选「0.99 · 预算耗尽」 | 默认先说明最后试算 500、复核未执行及本次无正式结果。末次绝对残差 0.0183974 mol/s 和缩放残差 0.00367947 均超限。可查看组分或定位工程流股和端口。 |
| 用 Tab／Enter 展开完整轨迹 | 两例分别显示 230 和 500 个真实样本，按阶段和阶段内序号排列。轨迹区可用键盘滚动；历史样本仅存两项最大值，组分明细标为未采集。 |

## 接线依据

- 顶部[活动栏](../../../../../apps/radishflow-studio/src/studio_gui_shell/background_run.rs)从进度取当前阶段，从最近完成的样本取其自身的阶段、序号与两项残差。启动、当前执行和末次记录均按[真实检查点](../../../../../crates/rf-solver/src/partitioned/execution.rs)解释。
- 成功与失败共用「流程运行 → 稳态运行计划 → 流程结果」里的判据和组分布局。[现有结果视图](../../../../../apps/radishflow-studio/src/studio_gui_shell/flow_plan/results.rs)分别读取成功块的回流报告和当前失败的活动回流报告。绝对值与对应容差同单位，两项比较都使用完整精度；本例工程的摩尔流量显示单位为 mol/s。总流量、温度及压力容差折叠在「其他检查」中。
- 成功动作沿[现有结果行定位](../../../../../apps/radishflow-studio/src/studio_gui_shell/variable_browser/navigation.rs)打开同一 Current 快照的流股；失败动作只定位工程对象。两种目标的局部预览均可返回。产品按[结果资格](../../../../../crates/rf-ui/src/result_query.rs)重验来源。画板用工程指纹、修订及请求步骤标明两份输入，原生运行显示编号由会话提供。
