## 数据与状态映射

- 以 `9a7e7e01` 的 CLI v13 对本机评审工程实际查询及复算。主画板是包含两条独立 H3 任务的 v4 示例，`E-301` 和 `E-302` 均有一条「水工况」。身份和结果按任务／工况 ID 匹配，可用同名工况复核切换隔离。热负荷为 5,521.71／5,877.49 W，环隙压降为 23,679.13／34,962.55 Pa。50 mol/s 的压降上限为 25,000 Pa，其余两项通过，仍展示完整结果。
- 两个失败场景是单独的 v3 示例。缺项移除有效换热长度，回执为 `missing_input`。越域把冷侧入口绝压设为 150,000 Pa，声明范围为 50,000–120,000 Pa，回执为 `inlet_outside_domain`。诊断保留 Core 稳定代码，数值结果区仅在复算完成时出现。
- 已保存输入与来源在执行前可见。待复算、当前结果和复算失败都有文字状态；有超限时，结果页顶部同时显示超限项数。复算行动只归所选工况，新开复核从待复算开始。诊断的「查看输入字段」展开已保存输入、标记并聚焦目标；「返回诊断」或 Escape 回到发起按钮，再按 Escape 关闭复核。
- 接线评审通过后，Studio 复用只读装载与应用层 `rate_saved_case`，以打开时的文件指纹和记录修订关联结果。画板按示例工程的 SI 单位显示。产品在已有量类使用该工程的显示单位，压降及 UA 仍分别以 Pa、W/K 展示。无产品编辑或写入入口。含未知任务或能力的工程沿用原文只读检查。 [CLI v13 契约](../../../../reference/headless-cli.md#h3-同心套管校核-cli-v13)
