# Studio N4 出口温度条件

2026-11-25，v1 局部交互已获项目所有者确认。面向要在 Mixer 出口过热时于 Flash 前检查流程的建模用户。项目所有者已确认「一次手动运行指定一个出口」及「监视值不可用时终止该次运行」。这份画板供评审字段、反馈位置和恢复路径。产品实现与原生验收另有[首批判据](../../../../topics/runtime-messages/scenarios-and-acceptance.md#n4-出口温度监视首批验收)。

## 打开画板

打开[可编辑交互画板](boards.html)。顶部「交互评审」工具栏负责选工况、切语言、改字号和演示执行器回执。下方才是 Studio 拟接入的控件。回执由评审者逐次送达，便于看清请求、停点确认和终态。画板的运行编号为演示数据，四组 Mixer 读数取自已有 CLI 的[工况记录](../../../../devlogs/2026-11/2026-W48.md#2026-11-25-n4-出口温度监视设计核对)。

| 评审路径 | 操作和应看到的结果 |
| --- | --- |
| 读数刚过阈值 | 默认选择「略高于阈值」、Mixer 出口和 38.85 °C。选「按此条件运行」，送达一次回执，显示运行 #21 的 312.0000006 K 高于 312 K，正等待边界。再送一次才显示 3/4、Flash 尚未开始，并提供单步与继续。此时正式结果仍来自 #20。继续或单步后再送达回执，结果归 #21。 |
| 读数相等或略低 | 选择「等于阈值」或「略低于阈值」，把输入单位切到 K。阈值回显 312 K。两种工况分别留下 312 K、311.9999994 K 及未命中原因，Flash 照常执行。 |
| 无快照或草稿无效 | 选择「尚无历史结果」，仍可以按已连接的物料出口设规则。选择「出口已重连」则须重选。输入未完成的 `1e-` 再尝试换单位或提交，文本和单位保留，原因显示在字段下方，焦点回到出错字段。 |
| 监视值缺失 | 选择「运行中缺值」并按条件运行。第一次回执说明 Mixer 步已完成、出口温度缺失，正在结束。再送一次，显示本次运行已终止、Flash 未开始，结果仍归 #20。「检查条件」把焦点带回出口。也可显式按 F5 普通运行，旧的缺值记录仍标原编号。 |
| 末步与模型失败 | 选择 Flash 气相出口、25 °C，末步的 300 K 命中并正常结束。另选「上游进料失败」监视 Mixer，保留 Feed B 组成错误和「本次未求值」。 |
| 修改下一次草稿 | 在 #21 的停点编辑阈值。表单换算跟随新草稿，运行栏和求值记录仍显示 #21 原阈值。取消本次运行保留已有正式结果。 |

## 产品接线与键盘约定

| 位置 | 行为 |
| --- | --- |
| [流程运行页](../../../../../apps/radishflow-studio/src/studio_gui_shell/flow_plan.rs) | 已应用无回路稳态计划的可编辑工程提供单条规则表单。「运行当前流程」和 F5 普通运行。「按此条件运行」在提交时核对出口、端口和流股身份，冻结数值及输入单位。表单可以编辑下一次草稿。 |
| [活动栏](../../../../../apps/radishflow-studio/src/studio_gui_shell/background_run.rs) | 到达边界前可以取消。停点经执行器确认后，显示命中出口、两侧数值、完成数和下一单元，复用 N3 的单步／继续／取消。缺值时显示具体出口和是否已终止。 |
| [计算过程](../../../../../apps/radishflow-studio/src/studio_gui_shell/execution_trace.rs)与结果 | 求值记录以运行编号关联已冻结规则，列出步序、规范阈值、输入单位、实测值与判断。即使显示精度相同也能读到实际差异。正式结果单列接收来源。画板聚焦最近一次受监视运行，原生历史选择沿用 N2。 |
| 键盘、窄区与反馈 | 阈值与单位相邻，400 px 时编辑区、求值记录及正式结果纵向排列。Tab 从停点状态依次到单步、继续、取消。动作消失时焦点回到状态。字段错误保留原文，缺值终态允许返回出口或显式普通运行。状态名称与数字均以文字表达。 |

首批后台行为以 [D-05](../../../../topics/runtime-messages/run-control-and-watch-conditions.md#d-05-无回路稳态出口温度监视提案)为准。评审关注运行前是否能读清目标和单位，停点能否区分观察值与正式结果，以及缺值后能否找到原因并恢复。原生接线可依现有 egui 区域调整间距和换行，保留操作顺序、运行身份与读数精度。
