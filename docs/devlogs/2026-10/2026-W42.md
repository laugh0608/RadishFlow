- 轴向依据不全时保留局部候选、缺失区段与原因；完整区段相加才能给切线间高度，工作量 / 缓冲量分别记录。非法轴向值不被静默丢弃。
- 不增加依赖、项目格式或产品入口；任务持久化、事务 / 历史、结果 current / stale 资格、UI 和 CSV / JSON 输出留后续批次。
