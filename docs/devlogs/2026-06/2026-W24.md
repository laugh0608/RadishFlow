## 关键决策

- 底部右侧 `状态汇总` 是 `window.status_summary` 的展示分栏，不是新的运行控制台、收敛曲线、结果报表或 snapshot 历史管理入口。
- 底部结果表仍是轻量结果审阅入口；完整报表、跨快照报表、模板、打印和批量导出继续留在暂不推进项。
- 对内容 renderer 的 focused test 与整体 Workbench 布局 focused test 分离，避免布局视口裁切误伤内容语义回归。
- `模块` 面板的筛选文本是临时 UI 状态，不是项目、命令、模块库或结果的真相源；分类依据来自现有 `StudioGuiCanvasPlaceUnitKind`。
- `项目` 面板分区只是现有项目 / canvas / snapshot 状态的职责组织，不新增完整项目浏览器、项目状态缓存或结果状态。
- 中央 Canvas 不再承担对象树 / 对象过滤导航；它只消费既有 canvas presentation 显示建模主舞台、轻量状态概览和受控建议，避免与左侧 `项目` 和右侧 `检查器` 重复。
- 右侧栏的 `画布选择` 是 Canvas presentation 的上下文提示，不是新的对象状态源；模块设置 / 模块结果仍只对 active unit DTO 生效，流股选择只进入检查器和现有 stream focus command。
