## 关键决策

- 底部右侧 `状态汇总` 是 `window.status_summary` 的展示分栏，不是新的运行控制台、收敛曲线、结果报表或 snapshot 历史管理入口。
- 底部结果表仍是轻量结果审阅入口；完整报表、跨快照报表、模板、打印和批量导出继续留在暂不推进项。
- 对内容 renderer 的 focused test 与整体 Workbench 布局 focused test 分离，避免布局视口裁切误伤内容语义回归。
- `模块` 面板的筛选文本是临时 UI 状态，不是项目、命令、模块库或结果的真相源；分类依据来自现有 `StudioGuiCanvasPlaceUnitKind`。
- `项目` 面板分区只是现有项目 / canvas / snapshot 状态的职责组织，不新增完整项目浏览器、项目状态缓存或结果状态。
- 中央 Canvas 不再承担对象树 / 对象过滤导航；它只消费既有 canvas presentation 显示建模主舞台、轻量状态概览和受控建议，避免与左侧 `项目` 和右侧 `检查器` 重复。
- 右侧栏的 `画布选择` 是 Canvas presentation 的上下文提示，不是新的对象状态源；模块设置 / 模块结果仍只对 active unit DTO 生效，流股选择只进入检查器和现有 stream focus command。
- 中央 Canvas 顶部工具区只承接视图和 suggestion 工具；选中对象的移动 / 连接恢复等命令归入 `画布操作`，放置入口归入左侧 `模块` 面板，对象语义详情归入右侧 `画布选择`，避免首屏重复展示同一选择状态。
- 底部薄状态栏是窗口级扫读带，不再承担完整状态汇总；完整 case / convergence / steps / diagnostics 仍由底部右侧 `状态汇总` 卡片消费同一 `window.status_summary`。
- 中央 Canvas 顶部工具区不再承接放置 palette；左侧 `模块` 面板是受控单元放置入口，中央只保留视图命令、当前建议命令和选中对象操作。
- 顶部 `流程图工具栏` 是 screen-level 上下文入口，不是第三个画布工具条；Canvas 段只保留已有 suggestion / pending-edit command，放置入口归左侧 `模块`，选中对象移动 / 连接动作归中央 `画布操作`。
- 普通空白项目的正式建模顺序是先 `物性` 再 `流程图`；Home 的当前 workspace tile 是当前文档的返回入口，不是 recent projects 持久化项，也不是第二套项目状态。
- `物性` 到 `流程图` 的 readiness 只表达 UI 主路径是否选齐 package 和项目组分；它不替代正式 run package resolution，也不改变 modeling readiness 对缺项目组分、缺 composition、参数缺失等求解前输入缺口的拦截边界。
