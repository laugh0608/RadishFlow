### 新增补验与成本实测

1. 相同两 Feed＋Mixer 的无环图，QS0—QS3 均独立求解为 `(2.2,2.8) mol/s`，原输出模板故意偏离解，源图不变。
2. 同一五单元单回流图（FA / FB / M0 / M1 / S1，没有原 QS1 公开例的下游 Heater），α=0 / 0.6 / 0.95 / 0.99。逐股对照 `m=f/(1−α)`、`r=αm`、`p=f`；比较误差 <1e-8 mol/s，核心自身原双残差 / 尺度门槛保持。α=1 时三方法均失败，保留 QS1 / QS2 的 NoFiniteSteadyState 与 QS3 的 LinearSingular 分类。
3. QS3-E1 的交叉回流追加同温压 H1；QS2 整图与独立分数一致，整图 EO 拒绝 H1。该事实为 QS4 的真实能力组合提供输入，不冒充混合求解成功。

定向命令：`CARGO_NET_OFFLINE=true cargo test --locked -p rf-solver strategy_acceptance -- --nocapture`，3 项通过。初次补验编写时两个 Rust 接口使用错误在编译阶段修正，未涉及产品缺陷或改动产品接口。
