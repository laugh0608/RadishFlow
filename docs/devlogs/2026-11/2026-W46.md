## 2026-11-10：C2-A 候选审阅与留出来源筛查

### 数值审阅

- 复核 [冻结协议、参数与验证包](../../../tests/thermo-validation/c2a-liquid-pressure-continuity/README.md)。固定 ChEDL 1.5.2 的公式文件和参数表 SHA-256 与记录一致，两条 CAS 参数与冻结文件一致。整个组成范围按相同规则计算广义 Pcm，修正 Rackett 饱和体积继续使用物理 Pc。原论文参数表认证仍待补。[固定公式](https://github.com/CalebBell/chemicals/blob/7fca9acf7708e2a646bc04d2b6f6996d0325e77d/chemicals/volume.py#L1552) · [固定参数表](https://github.com/CalebBell/chemicals/blob/7fca9acf7708e2a646bc04d2b6f6996d0325e77d/chemicals/Density/COSTALD%20Parameters.tsv)
- 264 条边界探查中，124 条可求值、84 条超出原温压域、56 条因低于关联 Ps 拒绝。端点压力规则衔接，压缩路径在原域内于 P=Ps 接上饱和体积。丙烷 `j.jct.2006.07.012/d1/p1` 是 280 K、581400 Pa 的实测 TP 密度，低于新关联 Ps 约 7.76 kPa，两候选仍明确拒绝。保留其 TP 身份与不可用记录。[原测量说明](https://trc.nist.gov/ThermoML/10.1016/j.jct.2006.07.012.html)
- 既有 47 点仍各为 46 pass / 1 unavailable，密度判据保持 5%。另按密度扩展不确定度复核，COSTALD 有 21/46、Rackett 有 19/46 超出所附区间。新增跨界点是 COSTALD 的正丁烷 `j.jct.2006.09.014/d3/p20`，由约 0.999 倍变为 1.010 倍扩展不确定度，仍满足原 5% 判据。不确定度对照单列，记录配对泡点的密度不确定度，并保留逐点相关性未知的限制。
- 552 行工程结果在候选名称映射后与上包逐字段一致。两个候选相对 HEOS 的直径均在 5% 内，各有 24/138 气负荷和 42/138 液负荷超过 10%。中部工况 `interior-T280-z0.5-scale10-R01` 的液负荷为 PR 0.976421、HEOS 1.024947、COSTALD 1.029530、Rackett 1.033898。由液负荷导致的 PR 与候选结论翻转保持，HEOS 为模型对照。

两个证据包共 23 项 Python 测试通过，独立算术复核覆盖 138 个密度值和 552 行工程结果。使用现有锁定 Rust harness 离线重放，输入、结果 TSV 和最终 JSON 与冻结文件逐字节一致。建议保留统一广义 Pcm 作为下一轮离线候选，继续以 COSTALD 为主、Rackett 为对照。现有证据支持数值一致性，连续物理域和工程资格仍待独立验证及审定。
