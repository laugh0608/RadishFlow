- 物性包选择必须成为项目模型的一部分，而不是运行按钮上的临时参数；运行时 `Preferred` 先尊重项目中保存的 package，再退回旧的单缓存包推断。
- 当前 Studio 物性包选择先采用受控内置列表，暂不引入第三方 Property Package 加载；后续项目组分选择应与该列表的适用组分边界对齐。

- Unit Inspector 的参数输入页属于 β 第二刀建模输入主路径，不按普通 presentation 小瑕疵处理；字段标签、单位、状态和操作必须保持可读，长约束说明只能作为辅助文本，不能挤压输入控件。
- official demo case 验收必须以用户可输入的项目状态和最新 `SolveSnapshot` 为准；不能只依赖仓库内静态示例 JSON 说明能力已经具备。
- MVP β 第二刀已收口，后续应先定下一组能力包；默认优先评估结果核对与案例说明，不回到已通过阶段的零散 UI 小项。

- 小案例作者清单可以继续保持只读提示层，但必须覆盖主路径输入就绪状态；拓扑完成不等于案例可运行。
- 缺少进料组成属于流股输入未就绪，不应由下游 Heater / Mixer / Flash 的泛化执行失败来承载；这类错误需要稳定诊断码、相关流股和可聚焦入口端口。
