## 风险与后续

- 今天的 Canvas 标签策略选择“空间不足时隐藏”，是 demo 可读性治理，不是自动布线或布局求解。若后续需要更高保真标签避让，应先作为 Canvas presentation 专题设计，不直接改 flowsheet 语义。
- 结果摘要仍使用组件 id 和相标签等领域标识，默认不翻译这些稳定数据字段；本轮只清理调试式前缀和默认正文结构。
- 选中流股恢复入口当前只处理 material stream 的受控断开 / 删除，以及 source-only 流股接到唯一可用 inlet 的重连。后续若用户需要“换接到另一个端口”，应先设计正式 command / validation / presentation 边界，不应把现有恢复入口顺手扩成自由连线编辑器。
- 关闭脏工作区提示复用当前项目操作通知条而不是新增模态弹窗；后续 UI 专题可以重新设计更明确的关闭确认样式，但行为边界应保持：脏工作区必须显式选择保存、舍弃或取消。
