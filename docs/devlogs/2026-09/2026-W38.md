## 关键决策

- 公共 API 不等于匿名公网接口；本地库、CLI、COM 不强制依赖云端 API key，远端请求需要凭据、主体、scope、资源及适用权益共同校验。
- 插件权限声明必须有运行时和宿主边界执行，进程内原生代码不宣称沙箱；高频数值调用不强制远端 RPC。
- 基础本地运行与受控资产租约分离；免费书面授权、无席位限制、具体组件许可证和授权模板仍待产品决策，根 `LICENSE` 未修改。
- 参考 RadishNexus 本地 `docs/licensing-strategy.md` 与 `docs/architecture/plugin-system.md`，读取日期 2026-09-14；只参考分层思路，未修改兄弟项目，也未把其文档规划写成运行时交付证据。
- 本轮仅修改文档，不改变产品代码、依赖、现有 PKCE / Bearer、资产缓存契约或 P1 / B1-4 的优先级，不触发提交、发布或部署。
